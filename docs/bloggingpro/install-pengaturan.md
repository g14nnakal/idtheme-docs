# Instalasi dan Pengaturan Bloggingpro

## Video Tutorial

Sebelum anda melangkah install bloggingpro, sebaiknya anda lihat video berikut sampai selesai.

<YouTubeEmbed video-id="0330hnlfLzE" />

## Langkah Instalasi
- Download file theme dari member area.
- Extract package yang sudah anda unduh, lalu anda upload bloggingpro.zip melalui **Appearance > Themes > Upload Theme**.
- Activate theme **Bloggingpro**.
- Install dan activate plugin rekomendasi/required yang diminta.

## Aktivasi Lisensi
- Masuk ke **Plugins > Bloggingpro License**.
- Masukkan license key yang didapat dari member area kentooz, silahkan kunjungi https://member.kentooz.com/softsale/license, untuk mendapatkan license key setelah anda login di memberarea.
- Simpan, pastikan status aktif agar theme dapat bekerja dengan baik.

## Import Demo
- Masuk ke **Appearance > Import Demo Data**.
- Klik Import Demo Data, install plugin required dan tunggu hingga selesai.
- Layout akan mengikuti demo, lanjutkan dengan menyesuaikan menu, widget dan customizer.

## Customizer

Buka **Appearance > Customize** untuk semua pengaturan tampilan. Contoh gambar pengaturan di Customizer:

![Bloggingpro Customizer Settings](/bloggingpro/install-pengaturan/bloggingpro-customizer-min.jpg)

Beberapa opsi penting di Customizer:
- **General:** layout fullwidth/boxed, background image, typography.
- **Header:** logo, gambar header, menu style, warna menu, sticky.
- **Homepage:** module home dan headline carousel.
- **Blog:** layout & konten (sticky sidebar, related posts, komentar facebook, dsb).
- **Banner:** kelola seluruh slot banner/ads.
- **Color:** general, header, menu, footer.
- **Footer:** copyright, jumlah widget.
- **Other:** script head/footer, analytics, pixel, optimasi.
- **Menus dan Widgets:** kelola navigasi & area widget.
- **Additional CSS:** tambahkan CSS kustom jika diperlukan.

## Persyaratan Server

Pastikan server hosting Anda memenuhi persyaratan berikut untuk performa optimal:
- Apache + PHP 7.4+ (disarankan versi terbaru).
- WordPress 5+ (disarankan versi terbaru).
- Curl Module dan OpenSSL aktif.

Data server diatas rekomendasi dari wordpress, jika anda menggunakan php versi 7.4 kebawah lebih baik di update ke versi 7.4+ mengingat masalah keamanan pada versi php lama.
