# Bloggingpro v1.0.7 Update

## New Features
- Very Top Banner: banner at the very top. Configure in **Customizer → Ads → Very Top Banner**.
- Secondary Menu: a secondary menu after the main menu. Configure in **Appearance → Menus**.
- Top Notification: short notification on the homepage. Configure in **Customizer → Homepage → Top Notification**.

## Changes
- Adjustments to several visual elements (e.g., image radius).
- Performance improvements and code quality fixes.
