# Free File Hosting

If you run a download or APK blog, you need reliable file hosting or storage to upload application files. Hosting files on your own server and having them downloaded by hundreds of users will quickly consume your hosting bandwidth.

Below are references to sites where you can upload ZIP, APK, or other application files for free:

- https://www.mediafire.com
- https://zippyshare.com
- https://www.4shared.com
- https://gofile.io
- https://mega.nz
- https://depositfiles.com
- https://www.file-upload.com
- https://usersdrive.com
- https://dropapk.to
- https://www.dropbox.com
- Google Drive
- https://www.box.com
- Onedrive
- http://upera.co

You can also use a CDN or private cloud, such as Google Cloud or Amazon.
