## Installation Steps

1. Download the Galepro theme from the member area.
2. Extract the package you received, then upload the `galepro.zip` file via **Appearance → Themes → Add New → Upload Theme**.
3. Activate the **Galepro** theme.
4. Install the recommended and required plugins, then activate all of them.

## License Activation

1. Go to **Plugins → Galepro License**.
2. Enter the license key obtained from the Kentooz member area: https://member.kentooz.com/softsale/license.
3. Save and ensure the license status is active so updates and support work properly.

## Import Demo Data

1. Go to **Appearance → Import Demo Data**.
2. Click the **Import Demo Data** button.
3. Wait a few minutes until the process completes.
4. After completion, the site will look similar to the official Galepro theme demo.
5. Continue by adjusting widgets and settings in the Customizer.

## Galepro Core Settings

The **galepro-core** plugin provides various built‑in theme features.  
Go to **Settings → Galepro Core** to configure them.

- **Author Box Tab**
  - Enable or disable the author box on single posts.
  - Configure author box colors and appearance.

- **Related Posts Tab**
  - Enable or disable related posts.
  - Set the number of posts shown in the related section.

- **Breadcrumbs Tab**
  - Enable breadcrumbs.
  - Configure breadcrumb text (e.g., the “Home” label and separator).

- **Gallery Tab**
  - Enable the theme’s built‑in gallery.
  - Configure the download button and auto description if available.

- **Ads Tab**
  - Configure ad codes in various theme positions.
  - Enable anti‑adblock scripts if used.

- **Social Tab**
  - Configure social share buttons.
  - Configure Open Graph (if not using a separate SEO plugin).

- **Other Tab**
  - Add custom scripts in the **head** and **footer** (e.g., Google Analytics, Facebook Pixel).
  - Optimization options such as disabling emoji scripts, script versioning, and more.

## Style Settings via Customizer

Theme appearance is configured through **Appearance → Customize**.

### General Tab

- Configure the general layout (boxed/fullwidth).
- Set primary colors (background, primary color).
- Set the site background image.
- Configure fonts:
  - Use Google Fonts.
  - Set sizes and colors for headings and body text.

### Header Tab

- Configure logo and site icon.
- Set header background color.
- Set header background image.
- Configure the header menu:
  - Menu position and layout.
  - Menu text, hover, and active colors.

### Blog Tab

- Configure blog/archive page layout:
  - Sidebar position (left/right/no sidebar).
  - Posts per page (follows WordPress Reading settings).

### Footer Tab

- Configure footer background color.
- Configure copyright text.
- Set the number of widgets displayed in the footer (e.g., 3 or 4 columns).

### Menus Tab

- Configure navigation menus (see the Galepro menu documentation as well).

### Widgets Tab

- Configure sidebars and widget modules (main sidebar, footer widgets, etc.).

### Additional CSS Tab

- Add custom CSS for advanced customization.

## Server Requirements

- Apache with PHP 7.4+ (supports PHP 7).
- WordPress 5+ (latest version recommended).
- Curl and JSON modules on the server (required).

For security reasons, it’s strongly recommended to use a PHP version newer than 7.4.
