# Posting a Gallery in Galepro

## Steps to Create a Gallery Post

1. Go to **Posts → Add New**.
2. Fill in the **title**, **description/content**, **category**, and **tags** as needed.
3. For gallery images:
   - Click the **Add Media** button in the editor.
   - Upload all images you want to display in the post.
   - No need to click **Insert into post** one by one, because the theme will display all images uploaded to that post as a gallery.
4. Choose one image as the **Featured Image** (main thumbnail).
5. Publish the post.

The Galepro theme will automatically render a gallery from the images uploaded to the post.

## Gallery Usage Tips

- Use consistent image sizes and aspect ratios so the gallery looks tidy.
- Compress images before uploading to maintain loading speed (see the performance optimization guide).
- Use clear file names (e.g., `film-1.jpg`, `film-2.jpg`) to make media management easier.
