# Solution to Add Icons to Menus in Idtheme Themes

Before following the steps, the original documentation provides a tutorial video for usage.

## Video Tutorial

Please watch the tutorial video as an initial guide.

<YouTubeEmbed video-id="ZC1VypobGWo" />

Some users want to add small icons next to menu text, such as Home, Search, or specific category icons.  
The recommended solution in Idtheme themes is to use the **Menu Icons** plugin.

Below are the complete steps.

## 1. Install the Menu Icons Plugin

1. Go to **Plugins → Add New**.
2. In the search field, type: `menu icons`.
3. Find the plugin named **Menu Icons** (ensure the name is: Menu Icons by ThemeIsle).
4. Click **Install Now**, then **Activate**.

Plugin link: https://wordpress.org/plugins/menu-icons/

After the plugin is active, icon settings will appear on the WordPress menus page. Example screenshot:

![Icon Settings in WordPress Menus](/general/menu/menu-icons.jpg)

## 2. Configure Icons in Appearance → Menus

1. Go to **Appearance → Menus**.
2. Choose the menu you want to edit (e.g., the main menu).
3. Click one of the menu items, such as **Home**.
4. After the plugin is active, an **Icons** setting appears inside that menu item.
5. Click the **Select** button in the Icons section. Screenshot:

![Icon Settings in the Home Menu Item](/general/menu/menu-icons-select-icons.jpg)

## 3. Choose an Icon from the Popup

After clicking **Select**:

1. An icon selection popup appears.
2. Choose any icon you want (e.g., a home icon for the Home menu).
3. On the right side of the popup, additional settings usually appear, such as:
   - Icon position (before/after text).
   - Spacing between icon and text.
4. When finished configuring, click **Select** in the popup. Screenshot:

![Icon Settings Preview for the Home Menu Item](/general/menu/menu-icons-select-icons-preview.jpg)

Back on the menus page, you will see a preview of the icon next to the menu label.

## 4. Save the Menu

After configuring icons for the desired menu items:

1. Scroll down.
2. Click **Save Menu**.

Icons will now appear on the front end for that menu.

## 5. Additional Notes and Compatibility

- Ensure icons don’t break the layout, especially on mobile.
- If your Idtheme provides built‑in icon settings in the Customizer:
  - Prefer using the theme’s built‑in features.
  - The Menu Icons plugin can complement if the built‑in features are insufficient.
- If the menu layout becomes messy after activating the plugin:
  - Temporarily deactivate the plugin to confirm the source of the issue.
  - Adjust CSS if necessary.

By following the steps above, you can easily add icons to menus in Idtheme themes using the Menu Icons plugin.
