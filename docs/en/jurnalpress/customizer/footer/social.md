# Social (Footer Layout) – JurnalPress Theme

The **Social** section is used to display **social media icons** in the footer area. The displayed social icon list follows the global settings in **Customizer → Footer Layout → Social**.

## Lokasi Pengaturan

```
Appearance → Customize → Footer Layout → Social
```

## Options

### Enable Social
**Customizer ID:** `*_socialfooter_active`  
**Type:** Toggle  

Enable the display of social icons in the footer.

**Default:** Enabled (1)

**Description:**  
Enable to display social icons in the footer. To configure the social list, go to **Customizer → Footer Layout → Social**.

**Shortcut:**  
A quick link is provided to the global social options.

## Notes on Social List Settings

Manage the list of social platforms (Facebook, Twitter, YouTube, etc.) along with **label** and **URL** at:

```
Appearance → Customize → Footer Layout → Social 
```

## Best Practice

- Display only relevant platforms to minimize distractions
- Use a common icon order (Facebook → Twitter → YouTube → Instagram)
- Ensure each URL is valid and uses HTTPS

## Ringkasan

The **Social (Footer Layout)** section enables social media icons in the footer area. The icon list and its display settings are managed globally via **Footer Layout → Social**.
