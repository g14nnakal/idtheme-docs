# Form (General) - JurnalPress Theme

The **Form** section configures the **global visual appearance of form elements** in the **JurnalPress** theme.  
These settings apply to all theme forms such as **input fields**, **textarea**, and other form elements used across the website (including comments, search forms, and more).

With these options, you can ensure form styling remains consistent with your site’s design and visual identity.

## Settings Location

Access these settings via:

```
Appearance → Customize → General → Form
```

All options are under the **Style** tab.

## Color

The **Color** option sets base colors for form elements.

### Available Settings

- **Background**  
  Set the form background color.

- **Text**  
  Set the text color displayed inside the form.

### Notes

- If left empty, colors follow the theme or browser defaults.
- Use good contrast to maintain readability.

## Border Radius

The **Border Radius** option controls corner roundness on forms.

### Features

- Supports **uniform** settings (same value for all sides)
- Supports **per side** settings (Top, Right, Bottom, Left)

### Usage

- Small radius gives a modern, crisp look
- Larger radius gives a soft, rounded appearance

## Padding

The **Padding** option controls spacing between form content and the element edges.

### Settings

Padding can be set independently for:

- Top
- Right
- Bottom
- Left

### Recommendations

Use sufficient padding so:
- Forms are comfortable to use
- Layout remains tidy on both desktop and mobile

## Border

The **Border** option controls form borders, including hover states.

### Available Settings

- **Enable Border**  
  Enable or disable the form border.

- **Border Color**  
  Border color in normal state.

- **Hover Color**  
  Border color on hover or focus.

- **Border Width**  
  Per‑side border thickness:
  - Top
  - Right
  - Bottom
  - Left

- **Border Style**  
  Border styles such as:
  - solid
  - dashed
  - dotted

### Default

By default, borders:
- Are enabled
- Have `1px` thickness
- Use the `solid` style

## Box Shadow

The **Box Shadow** option adds shadow effects to form elements.

### Available Settings

- **Enable**  
  Enable or disable box shadow.

- **Color**  
  Shadow color.

- **Horizontal Offset**  
  Horizontal distance of the shadow.

- **Vertical Offset**  
  Vertical distance of the shadow.

- **Blur**  
  Shadow blur intensity.

- **Spread**  
  Shadow spread amount.

### Notes

- Box shadows add visual depth
- Prefer light values to avoid distracting users

## Summary

The **Form** section lets you:

- Apply consistent form styling across the site
- Align form design with global theme styles
- Improve comfort and user experience

All settings are **global**, so changes apply immediately to all form elements using the JurnalPress theme’s default styles.
