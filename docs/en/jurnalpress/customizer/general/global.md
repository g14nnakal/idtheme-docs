# Global (General) - JurnalPress Theme

The **Global Settings** section lets you control site-wide appearance, layout, and behavior from one place. Changes here affect the entire website.

> 💡 **Tips:** Most settings support live preview.

## Settings Location
```
Appearance → Customize → General → Global
```

This section is divided into two tabs:
- **General** – layout, spacing, and content behavior
- **Style** – colors, background, and visual appearance

## Tab General

### Container Max Width
Set the maximum content width on large screens.

- Smaller values = tighter layout
- Larger values = wider layout

**Range:** 500px – 1250px

### Container Space
Control left and right spacing inside the container.

- Increase for more breathing room
- Decrease for a denser look

**Range:** 6px – 40px

### Thumbnail Hover Effect
Animation effect when hovering over post images.

**Choices:**
- None
- Zoom In
- Shine

### Layout
Choose the overall site layout structure.

**Default:** Full Layout

### Meta Related Posts
Configure the meta information shown on related posts.

- Reorder via drag & drop
- Hide on mobile if needed

### Meta Module & Widgets
Configure meta for post modules and widgets.

### Excerpt Length
Define the number of words in the post excerpt.

**Default:** 8 words

**Range:** 3 – 100 words

## Tab Style

### Color Scheme
Primary color used throughout the site. Can be replaced by other color settings.

### Grey Color
Grey tone for secondary text and UI elements.

### Border Color
Default border color.

### Background Color
Site background color or gradient.

### Background Image
Background image for the site body.

Configure position, transparency, size, and scroll behavior.

### Image Overlay Color
Overlay color applied to post thumbnails.

### Image Overlay Style
Image overlay style.

- Default
- Category Color

### Widget Title Style
Visual style for widget titles.

### Thumbnail Radius
Set corner roundness for thumbnails.

### Meta Separator
Separator symbol between post meta items.

### Meta Gap
Spacing between meta items.

**Range:** 4px – 40px
