# Typography (General) - JurnalPress Theme

Use the **Typography** menu to configure fonts, sizes, colors, and text styles globally in **JurnalPress**.  
These settings affect headings, body text, widgets, modules, excerpts, and other text elements across the site.

## Settings Location
```
Appearance → Customize → General → Typography
```
## Typography Tabs

Typography is divided into two main tabs:

- **General** → Primary font settings (Heading & Body)
- **Style** → Detailed typography for specific elements

## Tab: General

### Heading Font

Configure the font used for all headings, including:

- Post titles
- Page titles
- Heading H1 – H6
- Archive titles

**Available options:**

- Font Family (Google Fonts / System Fonts)
- Font Weight
- Font Style

> For headings, choose fonts that are strong and easy to read.

### Body Font

Set the main font for site content, such as:

- Article content
- Paragraphs
- Comments
- General text elements

**Available options:**

- Font Family
- Font Weight
- Font Style

> Choose a font that is comfortable for long‑form reading.

## Tab: Style

The **Style** tab contains advanced settings for each text element.

### Body

Configure detailed body text styling.

**Font Options:**

- Font Size
- Font Weight
- Text Transform (uppercase, lowercase, etc.)
- Line Height
- Font Style (italic, normal)

**Color Options:**

- Text Color
- Link Color
- Link Hover Color

**Font Size Limits:**

- Minimum: `8px`
- Maximum: `20px`

### Widget & Module Title

Typography settings for titles:

- Widgets
- Modules
- Archive titles
- Related post titles
- Comment titles

**Font Options:**

- Font Size
- Font Weight (default: **bold**)
- Text Transform
- Line Height
- Font Style

**Font Size Limits:**

- Minimum: `8px`
- Maximum: `40px`

> Useful for emphasizing important titles in sidebars and modules.

### Recent Title

Configure fonts for recent post titles shown in:

- Recent post widgets
- Recent post modules
- Related posts
- Other “recent” elements

**Important Notes:**

- Does not support color settings
- Does not support link and hover colors
- Custom colors/sizes can be set directly in each widget or module (if available)

**Font Size Limits:**

- Minimum: `8px`
- Maximum: `40px`

### Excerpt

Configure the default font for **excerpt** (content summary) text.

#### Excerpt Information

> Default excerpt font.  
> For custom colors and sizes, configure them directly in each module or widget if available.

#### Excerpt Font

**Font Options:**

- Font Size
- Font Weight
- Text Transform
- Line Height
- Font Style

**Font Size Limits:**

- Minimum: `8px`
- Maximum: `20px`

#### Excerpt Color

Set the global color for excerpt text.

> This option only affects excerpt text color, not titles or other elements.

## Usage Tips

- Use **Heading Font** that contrasts with **Body Font** to clarify text hierarchy
- Avoid overly small font sizes for readability
- Set **Line Height** appropriately to improve readability
- For consistent design, configure global settings first before per‑module adjustments

## Summary

Typography in JurnalPress gives you full control over:

- Site’s primary fonts
- Global text appearance
- Widget & module titles
- Recent post titles
- Excerpts

These settings help create a consistent, professional, and readable site experience.
