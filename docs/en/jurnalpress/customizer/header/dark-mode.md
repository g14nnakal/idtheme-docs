# Dark Mode (Header Layout) - JurnalPress Theme

The **Dark Mode** section enables a dark theme for the header area and elements that support dark mode in **JurnalPress**.

## Location in Customizer

```
Appearance → Customize → Header → Dark Mode
```

## Options

### Enable Dark Mode
**Customizer ID:** `*_darkmode_active`  
**Type:** Toggle  

Enable dark mode on the header.

**Default:** Enabled (1)

## Visual Impact

- Switches the header color scheme to darker tones (background, text, and icons follow the dark palette)
- Ensures high text contrast for readability
- Elements that support dark mode adapt automatically when enabled

## Best Practice

- Ensure text and icon colors have sufficient contrast against dark backgrounds
- Avoid very dark header images without proper contrast adjustments
- Test on mobile devices to confirm menu and icon readability

## Summary

The **Dark Mode** option provides a quick way to enable a dark header appearance, improving design consistency and comfort for users who prefer dark themes.
