# Site Identity (Header Layout) - JurnalPress Theme

The **Site Identity** section lets you configure your site’s identity in the header area, including **logo**, **site icon**, **site title**, and **tagline**.

## Location in Customizer

```
Appearance → Customize → Header → Site Identity
```

## Description

You can:
- Add a **Site Icon** (favicon) for browser tabs and mobile devices
- Upload a **Logo** to replace the site title in the header
- Change the site **Title** and **Tagline**

> Note: The tagline is hidden in the header. If a logo image is used, the **site title** appears as the logo image.

## Best Practice

- Use a logo with appropriate size and aspect ratio so it looks proportional in the header
- Provide a high‑resolution favicon for modern devices
- Ensure the site title is filled in for SEO and fallback purposes

## Summary

The **Site Identity** section serves as the central place to configure your site’s visual identity in the header, including logo, site icon, and title/tagline settings.
