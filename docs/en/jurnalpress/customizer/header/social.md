# Social (Header Layout) - JurnalPress Theme

The **Social** section displays **social media icons** in the header area. The icons shown follow the global configuration in **Customizer → General → Social**.

## Location in Customizer

```
Appearance → Customize → Header → Social
```

## Options

### Enable Social
**Customizer ID:** `*_socialheader_active`  
**Type:** Toggle  

Enable social icons in the header.

**Default:** Enabled (1)

**Description:**  
Enable to display social icons in the header. To configure the social list, go to **Customizer → General → Social**.

**Shortcut:**  
A quick link is provided to the global social options.

## Social List Settings Notes

Manage the list of social platforms (Facebook, Twitter, YouTube, etc.) and their **labels** and **URLs** in:

```
Appearance → Customize → General → Social
```

## Best Practice

- Show only relevant platforms to minimize distraction
- Use a familiar icon order (Facebook → Twitter → YouTube → Instagram)
- Ensure each URL is valid and uses HTTPS

## Summary

The **Social (Header)** section enables social media icons in the header. The icon list and appearance are managed globally via **General → Social**.
