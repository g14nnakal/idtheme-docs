# Home Bottom Module (Homepage) – JurnalPress Theme

## Description
The **Home Bottom Module** section manages the list of modules displayed at the bottom of the homepage.

## Settings Location
```
Appearance → Customize → Homepage → Home Bottom Module
```

## Control Type
- **btcorereact-sortable** — arrange module order and enable modules.

## Required Modules (cannot be removed)
- `post_slider`
- `widgets`
- `post_gridlist`

## Module Choices & Target Sections
- Post Slider → section: `post_slider_homebottom`
- Widgets → section: `widgets_homebottom`
- Post Grid/List → section: `post_gridlist_homebottom`
