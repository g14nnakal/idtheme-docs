# Home Top Module (Homepage) – JurnalPress Theme

## Description
The **Home Top Module** section manages the list of modules displayed at the top of the homepage.

## Settings Location
```
Appearance → Customize → Homepage → Home Top Module
```

## Control Type
- **btcorereact-sortable** — arrange module order and enable modules.

## Required Modules (cannot be removed)
- `post_slider`
- `post_banner`
- `widgets`
- `content_with_sidebar`
- `post_gridlist`

## Default Order
- Slider → Banner → Widgets → Content with Sidebar → Grid/List

## Module Choices & Target Sections
- Post Slider → section: `post_slider_hometop`
- Post Banner → section: `post_banner_hometop`
- Widgets → section: `widgets_hometop`
- Content with Sidebar → section: `content_with_sidebar_hometop`
- Post Grid/List → section: `post_gridlist_hometop`
