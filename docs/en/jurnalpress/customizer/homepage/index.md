## Description
The **Homepage** panel configures the composition of modules shown on the theme’s **front page**. This panel consists of:
- Modules in the top area: **Home Top Module**
- Additional option: **Latest Post With Sidebar**
- Modules in the bottom area: **Home Bottom Module**

## Settings Location
```
Appearance → Customize → Homepage
```

## Area Structure
- **Home Top Module**: top modules such as Post Slider, Post Banner, Widgets, Content with Sidebar, Post Grid/List.
- **Latest Post With Sidebar**: enable/disable the built‑in latest posts with sidebar list.
- **Home Bottom Module**: bottom modules such as Post Slider, Widgets, Post Grid/List.
