# Latest Post With Sidebar (Homepage) – JurnalPress Theme

## Description
Control the visibility of the **Latest Posts** list on the homepage using the archive layout with a sidebar.

## Settings Location
```
Appearance → Customize → Homepage → Latest Post With Sidebar
```

## Options
- **Disable Latest Post** (`btcore-toggle`, default: `0`/Off)
  - Disable the latest posts list on the homepage.

## Notes
- When the **Content with Sidebar** feature in Home Top is enabled, there is an offset in post numbering for the Latest Posts list below (see the Content with Sidebar documentation).
