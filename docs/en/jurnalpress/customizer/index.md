# Jurnalpress Theme Customizer

You can find the Customizer under **Appearance -> Customize** or **Tampilan -> Sesuaikan** in your site dashboard. The Customizer is primarily used by classic themes to make changes to the site’s appearance. This guide explains the most common options available in the Customizer.

## Configure Your Site Appearance Without Coding (Still Powerful)

The WordPress Customizer is a secret weapon for theme developers and everyday users. With the Customizer, you can change your site’s appearance in real time without refreshing the page—and without touching any code.
