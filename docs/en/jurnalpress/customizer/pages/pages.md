# Pages (Pages) – JurnalPress Theme

The **Pages** section is located at **Customizer → Pages → Pages** and is used to configure the display of static pages such as About, Contact, or other pages that use page templates.

Settings are divided into two main tabs: **General** and **Style**, making it easy to separate functional settings from visual appearance.

## Lokasi Pengaturan
```
Appearance → Customize → Pages → Pages
```

## General Settings

General settings related to the main elements of single pages.

### Breadcrumb

**Option:** Breadcrumb  
**Type:** Toggle

Enable or disable breadcrumbs on single pages.

- **ON** → Breadcrumb akan ditampilkan di bagian atas halaman.
- **OFF** → Breadcrumb tidak ditampilkan.

Breadcrumbs help user navigation and improve page SEO structure.

### Thumbnail

**Option:** Thumbnail  
**Type:** Toggle

Control whether the single page thumbnail (featured image) is displayed.

- **ON** → Thumbnail halaman akan ditampilkan.
- **OFF** → Thumbnail disembunyikan.

### Title

**Option:** Title  
**Type:** Toggle  
**Default:** Enabled

Control the visibility of the single page title.

- **ON** → Judul halaman ditampilkan.
- **OFF** → Judul halaman disembunyikan.

## Style Settings

Visual settings for the title and content on single pages.

### Alignment

**Option:** Alignment  
**Type:** SVG Button

Set the text alignment for the single page title.

Available alignment options:

- Left
- Center
- Right

### Title Font

**Option:** Title Font  
**Type:** Font Selector

Configure typography for the single page title.

Available settings:

- **Font Size**
- **Font Weight** (default: bold)
- **Text Transform**
- **Line Height**
- **Font Style** (Normal / Italic)

Font size range:

- Minimum: 8px
- Maximum: 40px

### Page Typography

**Option:** Page Typography  
**Type:** Section Label

A separator section for content typography settings on single pages.

### Content Font

**Option:** The Content Font  
**Type:** Font Selector

Configure typography for the main content on single pages.

Available settings:

- **Font Size**
- **Font Weight**
- **Text Transform**
- **Line Height**
- **Font Style**

Font size range:

- Minimum: 8px
- Maximum: 30px

## Ringkasan

The **Pages** section allows you to flexibly control the structure and appearance of single pages, from navigation elements and title visibility to typography details.

These settings are useful for aligning single page presentation with your site’s visual identity and improving user experience.
