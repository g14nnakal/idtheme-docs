# Sidebar (Pages) – JurnalPress Theme

The **Sidebar** section in the **Pages** panel of the JurnalPress Customizer is used to configure sidebar display and behavior across various page types, such as Archive, Single Post, Page, and Author Page. These settings help tailor content layout to suit design needs and user experience.

## Lokasi Pengaturan
```
Appearance → Customize → Pages → Sidebar
```

## Settings Tabs

This section consists of two main tabs:

- **General**: Configure sidebar position for each page type.
- **Style**: Configure sidebar behavior and visual appearance.

## Tab: General

### Archive Sidebar

Configure the sidebar position on archive pages (category, tag, date, and other archives).

**Options:**
- Uses visual controls (SVG Button).
- Default: `rightsidebar`.

**Sidebar Layout Choices:**
- **No Sidebar** (`nosidebar`) — Full‑width content without a sidebar.
- **No Sidebar Simple** (`simple`) — No sidebar with standard content width.
- **No Sidebar Narrow** (`narrow`) — No sidebar with narrower content.
- **Left Sidebar** (`leftsidebar`) — Sidebar on the left of content.
- **Right Sidebar** (`rightsidebar`) — Sidebar on the right of content.

### Single Sidebar

Configure the sidebar position on single post pages.

**Options:**
- Visual control using SVG Button.
- Default: `rightsidebar`.

**Sidebar Layout Choices:**
- No Sidebar
- No Sidebar Simple
- No Sidebar Narrow
- Left Sidebar
- Right Sidebar

### Default Page Sidebar

Configure the sidebar position on Pages (static pages).

**Options:**
- Visual control using SVG Button.
- Default: `narrow`.

**Sidebar Layout Choices:**
- No Sidebar
- No Sidebar Simple
- No Sidebar Narrow
- Left Sidebar
- Right Sidebar

### Author Page Sidebar

Configure the sidebar position on Author pages.

**Options:**
- Visual control using SVG Button.
- Default: `simple`.

**Sidebar Layout Choices:**
- No Sidebar
- No Sidebar Simple
- No Sidebar Narrow
- Left Sidebar
- Right Sidebar

## Tab: Style

### Sticky Sidebar

Enable or disable the sidebar to remain visible when scrolling.

**Options:**
- Toggle On/Off.
- Default: Enabled.

### Sticky Position Top

Define the distance of the sidebar from the top of the viewport when sticky mode is active.

**Options:**
- Range slider.
- Minimum value: 1.
- Maximum value: 200.
- Default follows theme configuration.

### Sidebar Size

Configure the sidebar width.

**Options:**
- Visual control (SVG Button).
- Size choices: Standard and Small.

## Catatan

- Each sidebar layout option is represented with an SVG icon for intuitive visual selection in the Customizer.
- The **No Sidebar** option is suitable for landing pages or content‑focused pages.
- **Sticky Sidebar** works best on layouts with left or right sidebars.
- These settings are global for each page type.
- Ensure sidebar widgets are configured via **Appearance → Widgets**.
