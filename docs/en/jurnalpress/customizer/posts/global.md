# Global (Single Post) – JurnalPress Theme

The **Global** section in the **Single Posts** panel configures the base (global) display for single post pages in the **JurnalPress** theme.

Settings here affect all single posts unless overridden by specific options in other sections.

## Lokasi Pengaturan
```
Appearance → Customize → Single Posts → Global
```

## Tabs
Settings are divided into two main tabs:

- **General** — configure structure and content elements
- **Style** — configure alignment and typography

## General Settings

### Breadcrumb
Enable or disable breadcrumbs on single post pages.

- **Default:** Enabled
- **Type:** Toggle

### Thumbnail
Show or hide the featured image (thumbnail) on single posts.

- **Default:** Enabled
- **Type:** Toggle

### Change Font Size Slide
Enable a slider to adjust content font size on single post pages (typically on the frontend).

- **Default:** Enabled
- **Type:** Toggle

### Floating Video
Enable a floating thumbnail video that appears in the bottom right corner of single post pages.

- **Default:** Enabled
- **Type:** Toggle

### Title Element
Informational section indicating title element settings, such as structure and positions related to the title.

### Style (Single Structure)
Set the header structure for single posts.

Available choices:
- **Style 1** — standard structure
- **Style 2** — alternate structure

- **Default:** Style 1
- **Type:** SVG Button

### Subtitle Position
Set the subtitle position relative to the title and meta.

Choices:
- **Default (After Title)** — subtitle after the title
- **After Meta** — subtitle after the meta
- **Before Title** — subtitle before the title

- **Default:** After Title

### Category
Show or hide categories in the single post header.

- **Default:** Enabled
- **Type:** Toggle

### Category Style
Configure the visual style for categories.

Choices:
- **No** — no special style
- **Label**
- **Icon**
- **Color Scheme**
- **Bg (Transparent)**
- **Bg (Solid)**

- **Default:** Bg (Transparent)

### Big Avatar
Display a large author avatar in the post header.

- **Default:** Enabled
- **Type:** Toggle

### Meta
Enable or disable primary meta (author, date, etc.).

- **Default:** Enabled
- **Type:** Toggle

### Lists Meta
Configure the list of primary meta items displayed.

Features:
- Drag & drop reordering
- Option to hide on mobile
- Additional per‑item style options

**Default meta:**
- Author
- Date

### Second Meta
Enable secondary meta.

- **Default:** Enabled
- **Type:** Toggle

### Second Lists Meta
Configure the list of secondary meta items displayed.

**Default meta:**
- Reading Time
- View

Same features as the primary Lists Meta:
- Sortable
- Hide on mobile
- Custom style

### View
Display the post view count.

> ⚠️ This feature requires a view counter plugin to function properly.

- **Default:** Enabled
- **Type:** Toggle

### Other Options
Marker section for additional single post options.

### Footer Tag
Display post tags in the content footer.

- **Default:** Enabled
- **Type:** Toggle

## Style Settings

### Alignment
Set alignment for main single post elements (title & meta).

Common choices:
- Left
- Center
- Right

- **Default:** Left
- **Type:** SVG Button

### Typography
Section for typography settings on single post content.

### Title Font
Configure post title typography.

Configurable properties:
- Font size
- Font weight
- Text transform
- Line height
- Font style

### Content Font
Configure typography for post content.

Configurable properties:
- Font size
- Font weight
- Text transform
- Line height
- Font style

## Catatan

- All settings in the **Global** section apply to all single posts.
- These settings can be combined with others like sidebar layout or related posts.
- For optimal results, align structure and typography with your site’s visual identity.
