# Widgets After Content (Module) – JurnalPress Theme

The **Widgets** section in the **Single Posts** panel configures and displays widgets **after the article content** on single post pages.

This setting does not add widgets directly from the Customizer; it serves as a **shortcut** to the corresponding WordPress Widgets settings.

## Lokasi Pengaturan
```
Appearance → Customize → Single Posts → After Content Element → Widgets
```

## Fungsi Utama

This section allows you to:

- Display widgets after the article content
- Direct users to WordPress Widgets settings
- Manage widgets via the dedicated **Module After Single** widget area

## Opsi yang Tersedia

### Notification: Informasi Widgets

**Description:**

Displays an informational notification explaining how to add widgets to the **After Single Post** area.

**Option details:**

- **Type:** Notification (Content)
- **Tab:** General
- **Function:** Information & navigation to Widgets settings
- **Target:** No Customizer page reload

**Pesan Notifikasi:**

> Note: To add widgets, please go to Appearance → Widgets or Customizer → Widgets. Drag widget to Module After Single.

### Tautan ke Pengaturan Widgets

The notification includes a quick link:

- **Label:** *Please go to widgets settings*
- **Tujuan:**  
  - `Appearance → Widgets`  
  - atau  
  - `Customizer → Widgets`

This link makes it easy to manage widgets without leaving the Single Posts configuration flow.

## Cara Menambahkan Widget After Content

1. Open **Appearance → Widgets**
2. Find the widget area named **Module After Single**
3. Drag & drop the desired widgets into that area
4. Save changes
5. Widgets automatically appear **after the article content** on single post pages

## Catatan Penting

::: info
The **Widgets** section in the Customizer **does not contain visual settings** or additional toggles.  
All widget management is done directly through the WordPress Widgets system.
:::

## Kapan Menggunakan Widgets After Content?

This widget area is suitable for:

- Related Posts
- Newsletter / Subscribe Form
- Iklan setelah artikel
- CTA (Call To Action)
- Informasi tambahan setelah konten utama
