# Installing the Jurnalpress Theme

This guide explains how to install the Jurnalpress WordPress theme from Idtheme.

Before installing Jurnalpress, please watch the following video to the end.

## Installation Steps

1. First download the theme **jurnalpress-v.x.x.xpacked.zip** from the member area; x.x.x is the theme version.
2. Extract the package you downloaded.
3. Upload the `jurnalpress.zip` file to WordPress via **Appearance -> Themes -> Upload Theme**.
4. Activate the Jurnalpress theme.

## License Activation

- Go to **Jurnalpress -> License Key**.
- Enter the license key obtained from the Kentooz member area in the license menu: https://member.kentooz.com/softsale/license.
- Save to activate the license for updates and support.

::: info
License issues & troubleshooting can be viewed [here](/guide/license-issue).
:::

## Import Demo Data

- Go to **Jurnalpress -> Dashboard**.
- Click **Install Demo Importer Plugin** and wait a moment until it finishes.
- After the demo importer plugin is installed, click **Go to Demo Importer Page** or go directly to **Jurnalpress -> Import Demo Data**.
- Choose the demo design you want to import.
- Click **Import Demo Data** and wait a few minutes. Continue by adjusting widgets and the customizer.

## System Requirements

Before installing the theme, ensure your hosting meets the following requirements:
- Latest WordPress version
- PHP version 7.4 or higher
- MySQL version 8 or higher
- MariaDB version 10.6 or higher
- https support

Additional requirements for the demo importer plugin:
- upload_max_filesize (256M)
- max_input_time (300)
- memory_limit (256M)
- max_execution_time (300)
- post_max_size (512M)
- php extensions: curl, xml, dom, and XMLReader
