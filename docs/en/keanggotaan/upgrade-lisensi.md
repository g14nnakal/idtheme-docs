# Upgrade Theme License

If you previously purchased a theme with a lower license (e.g., Personal) and want to upgrade to a higher license (e.g., Developer or more domains), you can do it directly from the Kentooz member area.

## 1. Check Whether the Theme Supports License Upgrades

Not all themes support license upgrades.  
Some themes provide only one license type, while others offer upgrade options to:
- Developer License
- Multi‑domain licenses (e.g., 5 domains, 200 domains, etc.)

To check:

1. Log in to your Kentooz account.
2. Open the **Active Subscriptions** page.
3. If your theme supports upgrades, an **Upgrade** button will appear on that subscription.

The upgrade button may look different over time, but it is usually next to the active subscription/theme information. Example:

![Upgrade License Button Example](/keanggotaan/upgrade-license/upgrade-button-idtheme.jpg)

## 2. Choose the Upgrade Type

After clicking **Upgrade**:

1. A popup with upgrade types will appear.
2. Select the desired upgrade, for example:
   - Upgrade to 5 domains.
   - Upgrade to 200 domains.
   - Upgrade to a Developer license.
3. Available options depend on the theme and package.

## 3. Complete the Upgrade Process

After choosing the upgrade type:

1. Click **Upgrade Subscription**.
2. You will be redirected to the payment method used during the initial purchase (e.g., PayPal or bank transfer).
3. Continue the payment process until completed.

After payment is confirmed:

- Your subscription will be upgraded to the new license.
- The upgrade price is usually the difference between the old and new license (details follow Kentooz’s system).

## 4. License Key Changes

Important notes:

- After upgrading, the **old license key will automatically become invalid**.
- The system will generate a **new license key** according to the new license.
- You need to:
  - Update the license key on sites using the theme.
  - Remove or replace the old license key with the new one.

If you want to **buy a new license key** while keeping the old license key (e.g., for a separate domain):
- Do not use the upgrade feature.
- Make a new purchase for the additional license.
