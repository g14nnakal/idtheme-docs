# Common Players Used in Muvipro

The Muvipro theme does not host video files itself; it displays players from external sources (embeds or links). Here are examples of player types/sources commonly used:

- Embeds from third‑party streaming services.
- Video files on a private server or CDN.
- HTML5 player with a direct link to `.mp4` or HLS files.

> Always comply with copyright requirements and the service's Terms of Service.

## Using Players in Muvipro

In the player meta box on Movie/Episode posts:

- Enter an iframe embed code, for example:

```html
<iframe src="https://contoh-streaming.com/embed/film-123" frameborder="0" allowfullscreen></iframe>
```

- Or enter a video URL if the theme provides an internal player.
