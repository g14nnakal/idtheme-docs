# Muvipro Infinite Scroll Settings

Muvipro supports infinite scroll (automatic load more) on archive pages using a Jetpack module or the theme’s built‑in integration.

## Notes

- For older versions of Muvipro (1.0.4 and earlier), infinite scroll requires the Jetpack plugin. In newer versions, Jetpack is no longer needed; use the theme’s built‑in feature.

## Enable Infinite Scroll

1. Go to **Customizer -> Movie -> Movie Layout**.
2. Configure **Blog Navigation Type** as needed:
   - **Infinite Scroll:** Automatically loads more posts when the user reaches the bottom of the page.
   - **Button Click:** A “Load more posts” button at the bottom of the page.
   - **Pagination:** Standard page navigation (1, 2, 3, etc.).

## Infinite Scroll Tips
- Keep your theme and plugins updated for best compatibility.
- Test performance:
  - Infinite scroll can feel “heavy” if too many items are loaded.
  - Use a reasonable number of posts per load.
