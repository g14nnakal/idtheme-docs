# How to Upgrade the Old Karma Theme to Newkarma for Free

If you previously purchased the **Karma** news theme (old version), you can upgrade to the **Newkarma** theme with a 1‑domain license for free.

## Differences Between the Old Karma and Newkarma

- **Different framework and features**:
  - Newkarma uses a newer framework and structure.
  - Features, layouts, and configuration methods are also different.
- **No “direct” upgrade without adjustments**:
  - If you use the old Karma theme, after switching to Newkarma you need to reconfigure the display from scratch (Customizer, widgets, etc.).

## General Upgrade Steps

1. **Make sure you officially purchased the old Karma theme.**
2. Read the **Newkarma** documentation to understand:
   - Theme installation.
   - Newkarma Core settings.
   - Customizer settings.
3. Use the Kentooz/Idtheme license upgrade guide:
   - Follow the official license upgrade procedure:  
     https://www.idtheme.com/docs/cara-upgrade-lisensi-untuk-theme-kentooz-atau-idtheme/

After the license upgrade process is complete, you will get access to the Newkarma theme.

## Confirm with the Developer

After upgrading:

1. **Confirm** with the Idtheme/Kentooz team:
   - Use the official contact page:  
     https://www.idtheme.com/kontak-kami/
   - Include:
     - Old Karma purchase details.
     - Member area account email.
     - Domain information where Newkarma will be used.
2. The team will verify and ensure the Newkarma license is active according to the terms.

## Notes on the Front Page

There is an important difference between the old Karma and Newkarma:

- **Old Karma**:
  - Uses a **static front page** (Front Page) as the homepage.
- **Newkarma**:
  - Uses **latest posts** as the homepage.

If, after the upgrade, the layout is not as expected, check these settings:

1. Go to **Settings → Reading**.
2. Under **Your homepage displays**:
   - Select **Your latest posts** to match Newkarma’s standard.
3. Save changes.

## Summary

- Upgrading from the old Karma to Newkarma is **free** for 1 domain.
- Newkarma is a new theme with different structure and features, so reconfiguration is required.
- Make sure to follow:
  - Newkarma installation & configuration guides.
  - The official license upgrade guide.
  - Reading settings (latest posts) after switching to Newkarma.

If you encounter issues during the upgrade or license activation, contact Idtheme/Kentooz support via the official contact page.
