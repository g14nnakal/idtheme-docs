# Salespro Theme Installation and Demo Import

The **Salespro** theme is designed for landing pages and product sales with Elementor support.

## Video Tutorial

The original documentation provides an installation guide video.  
Watch it first for clarity.

<YouTubeEmbed video-id="MQOQtB_5nmY" />

## Installation Steps
- Download the theme file from the member area.
- Extract the package you downloaded, then upload salespro.zip via **Appearance > Themes > Upload Theme**.
- Activate the **Salespro** theme.
- Install and activate **required** and **recommended** plugins (e.g., Elementor, contact plugins, etc.).

## Jetpack Settings (If Used)

Some Salespro features can leverage Jetpack modules, for example:

- **Contact Form**
- **Extra Sidebar Widgets**
- **Sharing**

Steps:

1. Go to the **Jetpack** menu in the dashboard.
2. Enable the required modules:
   - **Contact Form**
   - **Extra Sidebar Widgets**
   - **Sharing**

## Import Demo Data

After the theme and supporting plugins are active:

1. Go to **Appearance → Import Demo Data**.
2. Click **Import Demo Data**.
3. Wait a few minutes until the process completes.
4. If successful, your site will resemble the official Salespro demo.

After importing the demo:

- Review key pages (Home, Landing Page, Blog).
- Reconfigure menus and widgets if needed.

## Initial Customizer Setup

Most display settings can be configured via:

- **Appearance → Customize**

Example settings:

- Logo and favicon.
- Primary color and typography.
- Header/footer settings.
- Blog layout (if you use a blog).

## Server Requirements

- Apache with PHP **7.2+**.
- WordPress **5+** (latest version recommended).

If a blank screen or error occurs during installation:

- Ensure PHP and WordPress versions meet the recommendations.
- Check server upload limits and memory limit.
