# Configure the Blog Layout in Salespro

Although Salespro focuses on landing pages/sales, it also provides a blog layout.

All blog settings are managed via the **Customizer**.

## Open Blog Settings

1. Go to **Appearance → Customize**.
2. Find and click **Blog**.

Inside, there are typically two main tabs:

- **Blog Layout**
- **Blog Content**

## Blog Layout Tab

In this tab, you can configure:

- **Blog layout**:
  - Classic list.
  - Grid.
  - Other layouts provided by the theme.
- **Blog sidebar**:
  - Left sidebar.
  - Right sidebar.
  - No sidebar (fullwidth).
- **Single sidebar**:
  - Configure the sidebar for single post pages.
- **Blog style**:
  - For example, card, minimal, etc.

Make changes and preview on the right before clicking **Publish**.

## Blog Content Tab

In this tab, you can configure the content displayed in the blog listing:

- Disable **blog thumbnail**.
- Disable **single thumbnail**.
- Choose whether blog content uses:
  - **Excerpt**, or
  - **Full content**.

### Using Excerpt

- If you choose **excerpt**, only a short snippet is displayed.
- You can set:
  - Excerpt length (number of characters/words).
  - **Read More** text (e.g., “Read More”).

This is usually lighter and cleaner for post lists.

### Using Full Content

- If you use **full content**:
  - The entire post is displayed on the blog page.
  - It’s recommended to use the **Read More** tag in the editor to trim content neatly.
- See WordPress documentation on Read More:  
  https://codex.wordpress.org/Customizing_the_Read_More

## Number of Posts per Page

To set how many posts appear on blog/archive pages:

1. Go to **Settings → Reading**.
2. Under **Blog pages show at most**, enter the number of posts to display.
3. Save changes.

## Optimization Tips

- Use a simple layout if your site’s main focus is landing pages, to keep the blog lightweight.
- Avoid showing too many posts on one page to maintain speed.
- If using many images, compress them and use a lazy load plugin if necessary.
