# Latest Ad/Banner Placement in Superfast 1.0.8

Starting from version **1.0.8**, Superfast adds a **Banner Between Posts** feature to display ads between post listings on index and archive pages.

## Banner Between Posts on Index/Archive Pages

1. Go to **Settings → Idblog Core → Ads**.
2. Find the **Banner Between Posts** setting.
3. Paste your ad code (e.g., AdSense script or standard HTML banner).
4. Set the ad position, for example:
   - After the first post.
   - After the second post.
   - After the third post.
   - After the fourth post.
5. Save the settings.

After saving, the ad will appear between post lists according to the position you selected.

## Banners in Recent Posts and Most View Posts Widgets

Beyond the main loop, banner settings are available in:

- **Recent Posts (Idblog)** widget.
- **Most View Posts (Idblog)** widget.

Steps:

1. Go to **Appearance → Widgets**.
2. Edit the **Recent Posts (Idblog)** or **Most View Posts (Idblog)** widget.
3. At the bottom of the widget settings, you’ll find a banner option.
4. Paste your ad code into the available field.
5. Save the widget.

Notes:

- The **Most View Posts (Idblog Core)** widget requires an additional plugin:
  - [WP PostViews](https://wordpress.org/plugins/wp-postviews/) or [post views counter](https://wordpress.org/plugins/post-views-counter/).

## Supported Theme and Plugin Versions

This new banner feature is available only for:

- Superfast theme version **1.0.8** or later.
- **Idblog Core** plugin version **1.0.6** or later.

Make sure you update the theme and plugin before trying this feature.
