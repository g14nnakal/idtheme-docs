# How to Configure Menus in Superfast

Menu settings in Superfast follow WordPress standards, making them straightforward.

## Create a New Menu

1. Go to **Appearance → Menus**.
2. If no menu exists:
   - Enter a menu name, e.g., `Main Menu`.
   - Click **Create Menu**.
3. Under **Add menu items**, choose:
   - **Pages**: static pages such as Home, Contact, etc.
   - **Posts**: specific posts (rarely used for main menus).
   - **Custom Links**: for external links or anchor links.
   - **Categories**: news/article categories.
4. Check the items you want, then click **Add to Menu**.
5. Arrange the order using drag & drop.

## Configure Dropdown Menus

To create a dropdown menu:

1. Drag a menu item slightly to the right under its parent menu.
2. That item becomes a submenu of the item above.
3. Repeat for other submenus as needed.

Example structure:

- News
  - National
  - International
  - Sports

## Set Menu Locations

The Superfast theme typically provides these menu locations:

- **Primary** (main header menu).
- **Secondary** (if enabled, for the top bar).

Configure in **Appearance > Menus > Manage Locations**, assign a menu to each location, then Save Changes.

## Configure Menus in the Customizer

You can also configure menus via:

- **Appearance → Customize → Menus**.

Benefits:

- Real‑time preview.
- Useful for adjusting header colors and menu position together.

## Menu Structure Tips for Superfast
- Solution to add icons to the menu:
[Add Icons to Menu](/general/icon-menu-theme-idtheme.md)
- Use a concise menu; avoid too many levels.
- Place main categories at the first level.
- Subcategories at the second level.
- Avoid structures that confuse visitors.

After saving, refresh the homepage and ensure the menu displays as intended.
