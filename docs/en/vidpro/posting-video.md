# How to Post Videos in the Vidpro Theme

Vidpro focuses on video content. Below are general steps to create a video post.

Watch the tutorial video:

## Manual Video Posting

1. Go to **Posts → Add New**.
2. Fill in:
   - Post title.
   - Description/content.
   - Category and tags.
   - **Post Format: Video** (if supported by the theme).
3. Find the **Video Settings** meta box (usually below the editor):
   - Consists of 3 tabs:
     - **Video Settings**
     - **Iframe/Multi Server**
     - **Download**
4. In the **Video Settings** tab, there is a YouTube ID:
   - Enter the YouTube ID only
   - It will embed automatically.
   - Also fill in the duration.
5. If using **Iframe/Multi Server**:
   - Enter the `<iframe>` code provided by the video platform.
6. In the **Download** tab:
   - You can add download links to the post.
6. Choose a **Featured Image** for the thumbnail.
   - [Featured image tutorial.](https://wordpress.com/support/featured-images/)
7. Click **Publish**.
