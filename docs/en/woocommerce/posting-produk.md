# How to Post Products in WooCommerce

## Video Tutorial

## 1. Add a New Product
1. Go to **Products → Add New**.
2. Enter the **Product name** and main description.
3. Choose a product category and add tags if needed.

## 2. Product Data Settings
In the **Product data** meta box, choose the type:
- Simple product: a single product without variations.
- Variable product: a product with variations (color/size).
- Grouped product: a group of multiple simple products.
- External/Affiliate product: a product sold on another site (outbound link).

### Pricing and Inventory
- Regular price and Sale price (optional, can be scheduled).
- SKU (unique code), Manage stock, Quantity, and stock status.

### Shipping
- Weight and Dimensions for shipping cost calculation.
- Shipping class if using different shipping policies.

### Linked Products
- Upsells and Cross‑sells to increase sales.

### Advanced
- Purchase note and Menu order.

## 3. Variations (for Variable Products)
1. Open the **Attributes** tab, add attributes (e.g., Color, Size), check “Used for variations”.
2. Open the **Variations** tab, create variations from the added attributes.
3. Set price, stock, and image for each variation.

## 4. Short Description and Media
- Fill in the **Product short description** near the Add to cart button.
- Set the **Product image** (main image) and **Product gallery** (additional images).

## 5. Publish
1. Review the data and preview the product.
2. Click **Publish**.
3. Verify the product display on the **Shop** page and product details.
