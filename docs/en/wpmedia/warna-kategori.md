# How to Change Category Colors in Idtheme Themes

Currently, the supported theme is Wpmedia. Changing category colors in Idtheme is simple: go to **Posts -> Categories**. See the image below:

![Category Color Settings](/wpmedia/warna-kategori/wpmedia-categories-color-settings.jpg)

Then edit a category or add a new one. There is a “Color category” option—change the color there. See the image below:

![Category Color Picker](/wpmedia/warna-kategori/wpmedia-categories-color-options.jpg)

Done.
