## Langkah Membuat Posting Galeri

1. Masuk ke **Posts -> Add New**.
2. Isi **judul**, **deskripsi/konten**, **kategori**, dan **tag** sesuai kebutuhan.
3. Untuk gambar galeri:
   - Klik tombol **Add Media** di editor.
   - Upload semua image yang ingin anda tampilkan pada postingan tersebut.
   - Tidak perlu klik **Insert into post** satu per satu, karena theme akan menampilkan semua gambar yang diupload pada posting itu sebagai galeri.
4. Pilih satu gambar sebagai **Featured Image** (thumbnail utama postingan).
5. Publish postingan.

Theme Galepro akan secara otomatis membentuk tampilan galeri dari gambar-gambar yang diupload ke postingan tersebut.

## Tips Penggunaan Galeri

- Gunakan gambar dengan ukuran dan rasio yang konsisten agar galeri terlihat rapi.
- Kompres gambar sebelum upload untuk menjaga kecepatan loading (lihat juga panduan optimasi kecepatan).
- Gunakan nama file yang jelas (misalnya `film-1.jpg`, `film-2.jpg`) agar manajemen media lebih mudah.
