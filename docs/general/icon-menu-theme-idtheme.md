# Solusi Memberi Icon pada Menu di Theme Idtheme

Sebelum mengikuti langkah-langkah, pada dokumentasi asli disediakan video tutorial cara penggunaannya.

## Video Tutorial

Silahkan tonton video tutorial sebagai panduan awal.

<YouTubeEmbed video-id="ZC1VypobGWo" />

Beberapa pengguna ingin menambahkan icon kecil di sebelah teks menu, misalnya icon Home, Search, atau kategori tertentu.  
Solusi yang disarankan di theme Idtheme adalah menggunakan plugin **Menu Icons**.

Berikut langkah-langkah lengkapnya.

## 1. Instal Plugin Menu Icons

1. Masuk ke **Plugins → Add New**.
2. Pada kolom pencarian, ketik: `menu icons`.
3. Cari plugin bernama **Menu Icons** (Pastikan namanya: *Menu Icons by ThemeIsle*).
4. Klik **Install Now**, lalu klik **Activate**.

Link plugin Menu Icons: https://wordpress.org/plugins/menu-icons/

Setelah plugin aktif, pengaturan icon akan muncul di halaman menu WordPress. Contoh screenshot:

![Pengaturan Icon di Menu WordPress](/general/menu/menu-icons.jpg)

## 2. Mengatur Icon di Appearance → Menus

1. Masuk ke **Appearance → Menus**.
2. Pilih menu yang ingin anda edit (misalnya menu utama).
3. Klik salah satu item menu, misalnya **Home**.
4. Setelah plugin aktif, akan muncul pengaturan **Icons** di dalam item menu tersebut.
5. Klik tombol **Select** di bagian Icons. Screnshot:

![Pengaturan Icon di Item Menu Home](/general/menu/menu-icons-select-icons.jpg)

## 3. Memilih Icon dari Popup

Setelah klik **Select**:

1. Akan muncul popup pemilihan icon.
2. Pilih salah satu icon yang anda inginkan (misalnya icon rumah untuk menu Home).
3. Di sisi kanan popup biasanya terdapat pengaturan tambahan, misalnya:
   - Posisi icon (sebelum/sesudah teks).
   - Spasi antara icon dan teks.
4. Setelah selesai mengatur, klik **Select** di popup tersebut. Screnshot:

![Pengaturan Icon di Item Menu Home](/general/menu/menu-icons-select-icons-preview.jpg)

Kembali ke halaman menu, anda akan melihat preview icon di samping label menu.

## 4. Simpan Menu

Setelah selesai mengatur icon untuk item menu yang diinginkan:

1. Scroll ke bawah.
2. Klik **Save Menu**.

Sekarang icon akan tampil di front-end pada menu tersebut.

## 5. Catatan Tambahan dan Kompatibilitas

- Pastikan tampilan icon tidak merusak layout, terutama di versi mobile.
- Jika theme Idtheme sudah menyediakan pengaturan icon sendiri di Customizer:
  - Utamakan menggunakan fitur bawaan theme.
  - Plugin Menu Icons bisa menjadi pelengkap jika fitur bawaan belum mencukupi.
- Jika setelah mengaktifkan plugin tampilan menu menjadi tidak rapi:
  - Coba nonaktifkan plugin sementara untuk memastikan sumber masalah.
  - Sesuaikan CSS jika diperlukan.

Dengan mengikuti langkah-langkah di atas, anda dapat menambahkan icon pada menu di theme Idtheme dengan mudah menggunakan plugin Menu Icons.
