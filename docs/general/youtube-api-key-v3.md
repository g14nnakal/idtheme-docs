## Langkah Mendapatkan YouTube API Key v3

1. Silahkan anda kunjungi terlebih dahulu console cloud google, berikut adalah linknya: https://console.cloud.google.com dan jangan lupa login menggunakan gmail anda. Biasanya untuk pertama kali login akan muncul popup, pilih saja indonesia dan centang semua lalu klik agree, jika tidak muncul ya abaikan.

2. Langkah selanjutnya adalah membuat sebuah project pada website tersebut. Klik Create Project pada sebuah callout. Atau anda juga bisa klik Select Project pada drop down sebelah kanan tulisan Google Cloud Platform pada kiri atas.

![Create Youtube API Key](/general/youtube-api-key/create-project-youtube-api-key-select-project.jpg)

3. Isikan nama project anda(Nama Project Bebas) setelah anda klik New Project. Lalu klik Create.

![Create Youtube API Key](/general/youtube-api-key/isi-nama-project-google-api-key.jpg)

4. Masuk ke menu library untuk mengaktifkan library Youtube API Key v3 anda disini. Klik Library pada menu sebelah kiri.

![Create Youtube API Key](/general/youtube-api-key/api-key-youtube-menu-library.jpg)

5. Pada halaman Library silahkan anda cari Youtube Data API v3, anda klik, maka anda akan diarahkan ke laman pencarian dan menemukan Youtube Data API v3 library, lalu anda klik Youtube data API v3.

![Create Youtube API Key](/general/youtube-api-key/enable-youtube-data-api-v3.jpg)

6. Setelah itu anda klik enable, untuk mengaktifkan layanan Youtube Data API v3.

7. Maka anda akan diarahkan ke halaman dashboard project anda, untuk dapat menggunakan layanan ini, anda wajib membuat sebuah kredensial, silahkan anda buat terlebih dahulu kredensial untuk API tersebut, anda klik Create Credentials.

8. Tunggu beberapa saat, maka anda akan diarahkan ke halaman form untuk pembuatan kredensial. Silahkan anda pilih Youtube Data API v3, untuk pilihan “Which API are you using?” dan pilih public data untuk pilihan “What data will you be accessing? *” setelah itu anda klik tombol Next.

![Create Youtube API Key](/general/youtube-api-key/form-credensials-youtube-api-key.jpg)

9. Setelah klik next anda akan mendapatkan API Key anda, anda catat dimana terserah, notepad, atau dicatatan lain, setelah itu anda klik Done.

![Create Youtube API Key](/general/youtube-api-key/youtube-api-key-anda.jpg)

10. Selesai sampai disini. Anda bisa menggunakan API Key anda pada plugin youtube yang membutuhkan Youtube Data API v3. Untuk lebih realnya anda bisa melihat tutorial video diatas.

## Catatan Penting

- API Key yang anda buat hanya bisa digunakan pada project yang sama, jika anda membuat project baru, maka anda harus membuat API Key lagi.
- API Key yang anda buat hanya bisa digunakan pada domain yang sama, jika anda ingin menggunakan API Key pada domain lain, maka anda harus membuat API Key lagi.
- Diatas saya menggunakan google console bahasa inggris, kemungkinan anda menggunakan bahasa indonesia, tapi cara nya sama saja, tinggal translate saja.
- Tutorial ini dibuat desember 2021, kemungkinan juga suatu saat google merubah layout website nya, tapi kemungkinan cara nya sama saja.
