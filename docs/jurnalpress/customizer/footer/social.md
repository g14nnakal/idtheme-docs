# Social (Footer Layout)

Section **Social** digunakan untuk menampilkan **ikon media sosial** di area footer. Daftar ikon sosial yang tampil mengikuti pengaturan global di **Customizer → Footer Layout → Social**.

## Lokasi Pengaturan

```
Appearance → Customize → Footer Layout → Social
```

## Opsi

### Enable Social
**Customizer ID:** `*_socialfooter_active`  
**Type:** Toggle  

Mengaktifkan tampilan ikon sosial pada footer.

**Default:** Enabled (1)

**Description:**  
Aktifkan untuk menampilkan social icons di footer. Untuk pengaturan daftar sosial, pergi ke **Customizer → Footer Layout → Social**.

**Shortcut:**  
Disediakan tautan cepat menuju opsi global sosial.

## Catatan Pengaturan Daftar Sosial

Kelola daftar platform sosial (Facebook, Twitter, YouTube, dll.) beserta **label** dan **URL** di:

```
Appearance → Customize → Footer Layout → Social 
```

## Best Practice

- Tampilkan hanya platform yang relevan untuk meminimalkan distraksi
- Gunakan urutan ikon yang umum (Facebook → Twitter → YouTube → Instagram)
- Pastikan setiap URL valid dan menggunakan protokol HTTPS

## Ringkasan

Bagian **Social (Footer Layout)** mengaktifkan ikon media sosial di area footer. Daftar ikon dan pengaturan tampilannya dikelola secara global melalui **Footer Layout → Social**.
