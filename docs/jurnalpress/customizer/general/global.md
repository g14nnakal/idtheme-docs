# Global (General) - Theme Jurnalpress

Bagian **Global Settings** memungkinkan Anda mengatur tampilan, tata letak, dan perilaku website secara keseluruhan dari satu tempat. Semua perubahan di sini akan memengaruhi seluruh website.

> 💡 **Tips:** Sebagian besar pengaturan mendukung pratinjau langsung (live preview).

## Lokasi Pengaturan
```
Appearance → Customize → General → Global
```

Bagian ini terbagi menjadi dua tab:
- **General** – tata letak, spasi, dan perilaku konten
- **Style** – warna, latar belakang, dan tampilan visual

## Tab General

### Container Max Width
Mengatur lebar maksimum konten website di layar besar.

- Nilai kecil = tampilan lebih rapat
- Nilai besar = tampilan lebih lebar

**Rentang:** 500px – 1250px

### Container Space
Mengatur jarak kiri dan kanan di dalam container.

- Perbesar untuk ruang lebih lega
- Perkecil untuk tampilan lebih padat

**Rentang:** 6px – 40px

### Thumbnail Hover Effect
Efek animasi saat kursor diarahkan ke gambar postingan.

**Pilihan:**
- Tidak ada
- Zoom In
- Shine

### Layout
Memilih struktur tata letak website secara keseluruhan.

**Default:** Full Layout

### Meta Related Posts
Mengatur informasi meta yang ditampilkan pada postingan terkait.

- Bisa diurutkan (drag & drop)
- Bisa disembunyikan di perangkat mobile

### Meta Module & Widgets
Mengatur meta untuk modul postingan dan widget.

### Excerpt Length
Menentukan jumlah kata ringkasan (excerpt) postingan.

**Default:** 8 kata

**Rentang:** 3 – 100 kata

## Tab Style

### Color Scheme
Warna utama yang digunakan di seluruh website. Bisa di replace pada pengaturan warna lainnya.

### Grey Color
Warna abu-abu untuk teks sekunder dan elemen UI.

### Border Color
Warna garis tepi (border) default.

### Background Color
Warna atau gradasi latar belakang website.

### Background Image
Gambar latar belakang untuk body website.

Dapat diatur posisi, transparansi, ukuran, dan perilaku scroll.

### Image Overlay Color
Warna overlay pada thumbnail postingan.

### Image Overlay Style
Gaya overlay gambar.

- Default
- Warna Kategori

### Widget Title Style
Gaya tampilan judul widget.

### Thumbnail Radius
Mengatur tingkat lengkungan sudut thumbnail.

### Meta Separator
Simbol pemisah antar meta postingan.

### Meta Gap
Jarak antar item meta.

**Rentang:** 4px – 40px
