# Typography (General) - Theme Jurnalpress

Menu **Typography** digunakan untuk mengatur font, ukuran, warna, dan gaya teks secara global di theme **JurnalPress**.  
Pengaturan ini mempengaruhi tampilan heading, body text, widget, module, excerpt, dan elemen teks lainnya di seluruh website.

## Lokasi Pengaturan
```
Appearance → Customize → General → Typography
```
## Tabs pada Typography

Typography dibagi menjadi dua tab utama:

- **General** → Pengaturan font utama (Heading & Body)
- **Style** → Pengaturan detail tipografi untuk elemen tertentu

## Tab: General

### Heading Font

Mengatur font yang digunakan untuk semua heading, seperti:

- Judul posting
- Judul halaman
- Heading H1 – H6
- Judul arsip

**Opsi yang tersedia:**

- Font Family (Google Fonts / System Fonts)
- Font Weight
- Font Style

> Disarankan menggunakan font yang tegas dan mudah dibaca untuk heading.

### Body Font

Mengatur font utama untuk teks isi website, seperti:

- Konten artikel
- Paragraf
- Komentar
- Elemen teks umum

**Opsi yang tersedia:**

- Font Family
- Font Weight
- Font Style

> Pilih font yang nyaman dibaca untuk teks panjang.

## Tab: Style

Tab **Style** berisi pengaturan lanjutan untuk masing-masing elemen teks.

### Body

Mengatur gaya teks body secara detail.

**Opsi Font:**

- Font Size
- Font Weight
- Text Transform (uppercase, lowercase, dll)
- Line Height
- Font Style (italic, normal)

**Opsi Warna:**

- Text Color
- Link Color
- Link Hover Color

**Batas Ukuran Font:**

- Minimum: `8px`
- Maksimum: `20px`

### Widget & Module Title

Mengatur tipografi untuk judul:

- Widget
- Module
- Archive title
- Related post title
- Comment title

**Opsi Font:**

- Font Size
- Font Weight (default: **bold**)
- Text Transform
- Line Height
- Font Style

**Batas Ukuran Font:**

- Minimum: `8px`
- Maksimum: `40px`

> Cocok digunakan untuk menonjolkan judul elemen penting di sidebar dan module.

### Recent Title

Mengatur font untuk judul postingan terbaru yang muncul pada:

- Widget recent post
- Module recent post
- Related post
- Elemen recent lainnya

**Catatan Penting:**

- Tidak mendukung pengaturan warna
- Tidak mendukung warna link dan hover
- Warna dan ukuran khusus bisa diatur langsung di masing-masing widget atau module (jika tersedia)

**Batas Ukuran Font:**

- Minimum: `8px`
- Maksimum: `40px`

### Excerpt

Mengatur font default untuk teks **excerpt** (ringkasan konten).

#### Informasi Excerpt

> Default excerpt font.  
> Untuk warna dan ukuran khusus, silakan atur langsung di masing-masing module atau widget jika tersedia.

#### Font Excerpt

**Opsi Font:**

- Font Size
- Font Weight
- Text Transform
- Line Height
- Font Style

**Batas Ukuran Font:**

- Minimum: `8px`
- Maksimum: `20px`

#### Excerpt Color

Mengatur warna teks excerpt secara global.

> Opsi ini hanya mengatur warna teks excerpt, tidak mempengaruhi judul atau elemen lain.

## Tips Penggunaan

- Gunakan **Heading Font** yang kontras dengan **Body Font** agar hierarki teks jelas
- Jangan gunakan ukuran font terlalu kecil agar tetap nyaman dibaca
- Atur **Line Height** dengan baik untuk meningkatkan readability
- Untuk desain yang konsisten, gunakan pengaturan global terlebih dahulu sebelum mengatur per module

## Ringkasan

Typography di JurnalPress memberikan kontrol penuh terhadap:

- Font utama website
- Tampilan teks global
- Judul widget & module
- Recent post title
- Excerpt

Semua pengaturan ini membantu menciptakan tampilan website yang konsisten, profesional, dan nyaman dibaca.
