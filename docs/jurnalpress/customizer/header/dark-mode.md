# Dark Mode (Header Layout) - Theme Jurnalpress

Section **Dark Mode** digunakan untuk mengaktifkan mode gelap pada area header dan elemen yang mendukung tema gelap di **JurnalPress**.

## Lokasi di Customizer

```
Appearance → Customize → Header → Dark Mode
```

## Opsi

### Enable Dark Mode
**Customizer ID:** `*_darkmode_active`  
**Type:** Toggle  

Mengaktifkan mode gelap pada header.

**Default:** Enabled (1)

## Dampak Tampilan

- Mengubah skema warna header menjadi lebih gelap (background, teks, dan ikon mengikuti palet dark)
- Memastikan kontras teks tetap tinggi agar keterbacaan terjaga
- Elemen yang mendukung dark mode akan beradaptasi otomatis saat diaktifkan

## Best Practice

- Pastikan warna teks dan ikon memiliki kontras yang cukup terhadap background gelap
- Hindari penggunaan gambar header dengan latar sangat gelap tanpa penyesuaian kontras
- Uji tampilan pada perangkat mobile untuk memastikan keterbacaan menu dan ikon

## Ringkasan

Opsi **Dark Mode** memberikan cara cepat mengaktifkan tampilan gelap pada area header untuk konsistensi desain dan kenyamanan pengguna yang menyukai tema gelap.
