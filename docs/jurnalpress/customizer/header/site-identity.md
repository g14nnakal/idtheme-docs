# Site Identity (Header Layout) - Theme Jurnalpress

Section **Site Identity** memungkinkan Anda mengatur identitas situs pada area header, seperti **logo**, **ikon situs**, serta **site title** dan **tagline**.

## Lokasi di Customizer

```
Appearance → Customize → Header → Site Identity
```

## Deskripsi

Anda dapat:
- Menambahkan **Site Icon** (favicon) untuk tab browser dan perangkat mobile
- Mengunggah **Logo** untuk menggantikan site title di header
- Mengubah **Site Title** dan **Tagline** situs

> Catatan: Tagline tersembunyi pada header. Jika menggunakan gambar logo, maka **site title** akan tampil sebagai logo gambar.

## Best Practice

- Gunakan logo dengan ukuran dan rasio yang sesuai agar tampil proporsional di header
- Siapkan favicon resolusi tinggi untuk dukungan perangkat modern
- Pastikan site title tetap diisi untuk keperluan SEO dan fallback

## Ringkasan

Bagian **Site Identity** berfungsi sebagai pusat pengaturan identitas visual situs di area header, mencakup logo, ikon situs, serta pengaturan judul/tagline.
