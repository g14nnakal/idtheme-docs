# Social (Header Layout) - Theme Jurnalpress

Section **Social** digunakan untuk menampilkan **ikon media sosial** di area header. Daftar ikon sosial yang tampil mengikuti pengaturan global di **Customizer → General → Social**.

## Lokasi di Customizer

```
Appearance → Customize → Header → Social
```

## Opsi

### Enable Social
**Customizer ID:** `*_socialheader_active`  
**Type:** Toggle  

Mengaktifkan tampilan ikon sosial pada header.

**Default:** Enabled (1)

**Description:**  
Aktifkan untuk menampilkan social icons di header. Untuk pengaturan daftar sosial, pergi ke **Customizer → General → Social**.

**Shortcut:**  
Disediakan tautan cepat menuju opsi global sosial.

## Catatan Pengaturan Daftar Sosial

Kelola daftar platform sosial (Facebook, Twitter, YouTube, dll.) beserta **label** dan **URL** di:

```
Appearance → Customize → General → Social
```

## Best Practice

- Tampilkan hanya platform yang relevan untuk meminimalkan distraksi
- Gunakan urutan ikon yang umum (Facebook → Twitter → YouTube → Instagram)
- Pastikan setiap URL valid dan menggunakan protokol HTTPS

## Ringkasan

Bagian **Social (Header)** mengaktifkan ikon media sosial di area header. Daftar ikon dan pengaturan tampilannya dikelola secara global melalui **General → Social**.
