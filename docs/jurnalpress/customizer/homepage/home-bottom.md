# Home Bottom Module (Homepage) – Theme JurnalPress

## Deskripsi
Section **Home Bottom Module** mengatur daftar modul yang ditampilkan di bagian bawah homepage.

## Lokasi Pengaturan
```
Appearance → Customize → Homepage → Home Bottom Module
```

## Tipe Kontrol
- **btcorereact-sortable** — menyusun urutan modul dan mengaktifkan modul.

## Daftar Modul Wajib (tidak bisa dihapus)
- `post_slider`
- `widgets`
- `post_gridlist`

## Pilihan Modul & Section Tujuan
- Post Slider → section: `post_slider_homebottom`
- Widgets → section: `widgets_homebottom`
- Post Grid/List → section: `post_gridlist_homebottom`
