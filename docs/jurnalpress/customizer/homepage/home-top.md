# Home Top Module (Homepage) – Theme JurnalPress

## Deskripsi
Section **Home Top Module** mengatur daftar modul yang ditampilkan di bagian atas homepage.

## Lokasi Pengaturan
```
Appearance → Customize → Homepage → Home Top Module
```

## Tipe Kontrol
- **btcorereact-sortable** — menyusun urutan modul dan mengaktifkan modul.

## Daftar Modul Wajib (tidak bisa dihapus)
- `post_slider`
- `post_banner`
- `widgets`
- `content_with_sidebar`
- `post_gridlist`

## Default Urutan
- Slider → Banner → Widgets → Content with Sidebar → Grid/List

## Pilihan Modul & Section Tujuan
- Post Slider → section: `post_slider_hometop`
- Post Banner → section: `post_banner_hometop`
- Widgets → section: `widgets_hometop`
- Content with Sidebar → section: `content_with_sidebar_hometop`
- Post Grid/List → section: `post_gridlist_hometop`
