# Homepage (Customizer) – Theme JurnalPress

## Deskripsi
Panel **Homepage** mengatur komposisi modul yang tampil di halaman depan (front page) tema **JurnalPress**. Panel ini terdiri dari:
- Modul di area atas: **Home Top Module**
- Opsi tambahan: **Latest Post With Sidebar**
- Modul di area bawah: **Home Bottom Module**

## Lokasi Pengaturan
```
Appearance → Customize → Homepage
```

## Struktur Area
- **Home Top Module**: kumpulan modul atas seperti Post Slider, Post Banner, Widgets, Content with Sidebar, Post Grid/List.
- **Latest Post With Sidebar**: mengaktifkan/menonaktifkan daftar post terbaru dengan sidebar bawaan.
- **Home Bottom Module**: kumpulan modul bawah seperti Post Slider, Widgets, Post Grid/List.
