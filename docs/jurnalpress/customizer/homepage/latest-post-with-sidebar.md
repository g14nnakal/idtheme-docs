# Latest Post With Sidebar (Homepage) – Theme JurnalPress

## Deskripsi
Mengatur visibilitas daftar **Latest Posts** pada homepage menggunakan layout arsip dengan sidebar.

## Lokasi Pengaturan
```
Appearance → Customize → Homepage → Latest Post With Sidebar
```

## Opsi
- **Disable Latest Post** (`btcore-toggle`, default: `0`/Off)
  - Menonaktifkan daftar post terbaru pada homepage.

## Catatan
- Ketika fitur **Content with Sidebar** di Home Top diaktifkan, terdapat offset nomor post untuk daftar Latest Posts di bawah (lihat dokumen Content with Sidebar).
