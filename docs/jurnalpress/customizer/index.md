# Customizer Theme Jurnalpress

Customizer dapat ditemukan dengan membuka **Appearance -> Customize** atau **Tampilan -> Sesuaikan** di dasbor situs Anda. Customizer utamanya digunakan oleh tema klasik untuk membuat perubahan pada tampilan situs. Panduan ini akan menjelaskan pilihan yang paling lazim ditemukan di Customizer.

## Mengatur Tampilan Website Tanpa Coding (Tapi Tetap Powerful)

Customizer WordPress adalah senjata rahasia bagi theme developer dan user awam. Dengan Customizer, kamu bisa mengubah tampilan website secara real-time tanpa perlu refresh halaman, bahkan tanpa menyentuh kode sama sekali.
