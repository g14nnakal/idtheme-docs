# Pages (Pages) – Theme JurnalPress

Section **Pages** berada pada **Customizer → Pages → Pages** dan digunakan untuk mengatur tampilan halaman statis seperti halaman about, contact, atau halaman lainnya yang menggunakan template halaman.

Pengaturan ini dibagi ke dalam dua tab utama: **General** dan **Style**, sehingga memudahkan pemisahan antara pengaturan fungsional dan tampilan visual.

## Lokasi Pengaturan
```
Appearance → Customize → Pages → Pages
```

## General Settings

Pengaturan umum yang berkaitan dengan elemen-elemen utama halaman single page.

### Breadcrumb

**Opsi:** Breadcrumb  
**Tipe:** Toggle

Mengaktifkan atau menonaktifkan breadcrumb pada halaman single page.

- **ON** → Breadcrumb akan ditampilkan di bagian atas halaman.
- **OFF** → Breadcrumb tidak ditampilkan.

Breadcrumb membantu navigasi pengguna dan meningkatkan struktur SEO halaman.

### Thumbnail

**Opsi:** Thumbnail  
**Tipe:** Toggle

Mengatur apakah thumbnail (featured image) halaman single page ditampilkan atau tidak.

- **ON** → Thumbnail halaman akan ditampilkan.
- **OFF** → Thumbnail disembunyikan.

### Title

**Opsi:** Title  
**Tipe:** Toggle  
**Default:** Aktif

Mengontrol visibilitas judul halaman single page.

- **ON** → Judul halaman ditampilkan.
- **OFF** → Judul halaman disembunyikan.

## Style Settings

Pengaturan visual untuk judul dan konten pada halaman single page.

### Alignment

**Opsi:** Alignment  
**Tipe:** SVG Button

Menentukan perataan teks judul halaman single page.

Pilihan alignment yang tersedia:

- Left (Kiri)
- Center (Tengah)
- Right (Kanan)

### Title Font

**Opsi:** Title Font  
**Tipe:** Font Selector

Mengatur tipografi judul halaman single page.

Pengaturan yang tersedia:

- **Font Size** – Ukuran teks judul
- **Font Weight** – Ketebalan teks (default: bold)
- **Text Transform** – Uppercase, lowercase, dll
- **Line Height** – Jarak antar baris
- **Font Style** – Normal / Italic

Rentang ukuran font:

- Minimum: 8px
- Maksimum: 40px

### Page Typography

**Opsi:** Page Typography  
**Tipe:** Section Label

Bagian pemisah untuk pengaturan tipografi konten halaman single page.

### Content Font

**Opsi:** The Content Font  
**Tipe:** Font Selector

Mengatur tipografi konten utama pada halaman single page.

Pengaturan yang tersedia:

- **Font Size**
- **Font Weight**
- **Text Transform**
- **Line Height**
- **Font Style**

Rentang ukuran font:

- Minimum: 8px
- Maksimum: 30px

## Ringkasan

Section **Pages** memungkinkan Anda mengontrol struktur dan tampilan halaman single page secara fleksibel, mulai dari elemen navigasi, visibilitas judul, hingga detail tipografi.

Pengaturan ini sangat berguna untuk menyesuaikan tampilan single page agar konsisten dengan identitas visual website dan meningkatkan pengalaman pengguna.
