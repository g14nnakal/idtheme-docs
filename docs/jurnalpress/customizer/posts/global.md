# Global (Single Post) – Theme JurnalPress

Section **Global** pada panel **Single Posts** digunakan untuk mengatur tampilan dasar (global) halaman single post di theme **JurnalPress**.

Pengaturan di sini akan memengaruhi semua single post, kecuali jika ditimpa oleh pengaturan khusus di section lain.

## Lokasi Pengaturan
```
Appearance → Customize → Single Posts → Global
```

## Tab Pengaturan
Pengaturan dibagi ke dalam dua tab utama:

- **General** — mengatur struktur dan elemen konten
- **Style** — mengatur perataan dan tipografi

## General Settings

### Breadcrumb
Mengaktifkan atau menonaktifkan breadcrumb pada halaman single post.

- **Default:** Aktif
- **Tipe:** Toggle

### Thumbnail
Menampilkan atau menyembunyikan featured image (thumbnail) pada single post.

- **Default:** Aktif
- **Tipe:** Toggle

### Change Font Size Slide
Mengaktifkan fitur slider untuk mengubah ukuran font konten di halaman single post (biasanya di sisi frontend).

- **Default:** Aktif
- **Tipe:** Toggle

### Title Element
Section informasi yang menandai pengaturan elemen judul post, seperti struktur dan posisi elemen terkait judul.

### Style (Single Structure)
Menentukan struktur layout header single post.

Pilihan yang tersedia:
- **Style 1** — struktur standar
- **Style 2** — variasi struktur alternatif

- **Default:** Style 1
- **Tipe:** SVG Button

### Subtitle Position
Menentukan posisi subtitle terhadap judul dan meta.

Pilihan:
- **Default (After Title)** — subtitle setelah judul
- **After Meta** — subtitle setelah meta
- **Before Title** — subtitle sebelum judul

- **Default:** After Title

### Category
Menampilkan atau menyembunyikan kategori pada header single post.

- **Default:** Aktif
- **Tipe:** Toggle

### Category Style
Mengatur tampilan visual kategori.

Pilihan:
- **No** — tanpa gaya khusus
- **Label**
- **Icon**
- **Color Scheme**
- **Bg (Transparent)**
- **Bg (Solid)**

- **Default:** Bg (Transparent)

### Big Avatar
Menampilkan avatar penulis dalam ukuran besar pada header post.

- **Default:** Aktif
- **Tipe:** Toggle

### Meta
Mengaktifkan atau menonaktifkan meta utama (author, date, dll).

- **Default:** Aktif
- **Tipe:** Toggle

### Lists Meta
Mengatur daftar meta utama yang ditampilkan.

Fitur:
- Drag & drop untuk mengubah urutan
- Opsi sembunyikan di mobile
- Opsi style tambahan per item

**Default meta:**
- Author
- Date

### Second Meta
Mengaktifkan meta tambahan (secondary meta).

- **Default:** Aktif
- **Tipe:** Toggle

### Second Lists Meta
Mengatur daftar meta sekunder yang ditampilkan.

**Default meta:**
- Reading Time
- View

Fitur sama seperti Lists Meta utama:
- Sortable
- Hide on mobile
- Custom style

### View
Menampilkan jumlah view post.

> ⚠️ Fitur ini memerlukan plugin view counter agar dapat berfungsi dengan baik.

- **Default:** Aktif
- **Tipe:** Toggle

### Other Options
Section penanda untuk opsi tambahan pada single post.

### Footer Tag
Menampilkan tag post di bagian footer konten.

- **Default:** Aktif
- **Tipe:** Toggle

## Style Settings

### Alignment
Mengatur perataan elemen utama single post (judul & meta).

Pilihan umum:
- Left
- Center
- Right

- **Default:** Left
- **Tipe:** SVG Button

### Typography
Section untuk pengaturan tipografi konten single post.

### Title Font
Mengatur tipografi judul post.

Properti yang dapat diatur:
- Font size
- Font weight
- Text transform
- Line height
- Font style

### Content Font
Mengatur tipografi isi konten post.

Properti yang dapat diatur:
- Font size
- Font weight
- Text transform
- Line height
- Font style

## Catatan

- Semua pengaturan di section **Global** berlaku untuk seluruh single post.
- Pengaturan ini dapat dikombinasikan dengan pengaturan lain seperti layout sidebar atau related post.
- Untuk hasil optimal, sesuaikan struktur dan tipografi dengan identitas visual website Anda.
