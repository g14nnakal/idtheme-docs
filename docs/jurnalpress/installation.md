# Instalasi Theme Jurnalpress

Panduan ini akan menjelaskan cara menginstal theme Jurnalpress WordPress dari Idtheme.

## Langkah Instalasi

1. Download terlebih dahulu theme **jurnalpress-v.x.x.xpacked.zip** dari member area x.x.x adalah versi theme.
2. Extract paket yang anda unduh.
3. Upload file `jurnalpress.zip` ke WordPress melalui **Appearance -> Themes -> Upload Theme**.
4. Aktifkan theme Jurnalpress.

## Aktivasi Lisensi

- Masuk ke Menu **Jurnalpress -> License Key**.
- Masukkan license key yang didapat dari member area kentooz pada menu license: https://member.kentooz.com/softsale/license.
- Simpan agar lisensi aktif untuk update dan dukungan.

## Import Demo Data

- Masuk ke Menu **Jurnalpress -> Dashboard**.
- Klik tombol **Install Demo Importer Plugin** tunggu beberapa saat sampai selesai.
- Setelah plugin demo importer terinstal, klik tombol **Go to Demo Importer Page** atau langsung menuju ke **Jurnalpress -> Import Demo Data**.
- Pilih desain demo yang ingin diimport.
- Klik tombol **Import Demo Data** dan tunggu beberapa menit. Lanjutkan dengan menyesuaikan widget dan customizer.

## Persyaratan Sistem

Sebelum menginstal theme, pastikan hosting Anda memenuhi persyaratan berikut:
- WordPress versi terbaru
- PHP versi 7.4 atau lebih tinggi
- MySQL versi 8 atau lebih tinggi
- Maria DB versi 10.6 atau lebih tinggi
- https support

Persyaratan tambahan untuk plugin demo importer:
- upload_max_filesize (256M)
- max_input_time (300)
- memory_limit (256M)
- max_execution_time (300)
- post_max_size (512M)
- php extension: curl, xml, dom, dan XMLReader

Whitelist link ke domain https://member.kentooz.com dan https://www.github.com
