# Cara Melakukan Pembelian Theme

Panduan ini menjelaskan langkah demi langkah membeli theme dari Kentooz / Idtheme.

Sebelumnya, silahkan tonton video tutorial berikut untuk panduan lengkap:

## 1. Memilih Theme

1. Buka halaman produk theme yang anda minati (misalnya Muvipro, Majalahpro, dsb).
2. Pada tabel harga, klik tombol **Beli Theme**.
3. Anda akan diarahkan ke halaman form pembelian di website Kentooz.

Contoh tampilan tombol beli bisa berbeda untuk setiap produk, namun umumnya berada di bagian harga/paket theme. Contoh gambar berikut:

![Contoh Tombol Beli Theme](/keanggotaan/beli-theme/tombol-beli-theme.jpg)

## 2. Mengisi Form Pembelian / Membuat Akun

Pada halaman pembelian:

- Jika belum punya akun:
  - Isi data diri pada form pendaftaran (nama, email, dsb).
  - Buat password untuk akun Kentooz anda.
- Jika sudah punya akun:
  - Klik **Login** terlebih dahulu, lalu lanjutkan memilih produk.

Anda bisa:
- Mengubah bahasa ke Bahasa Indonesia (jika tersedia).
- Login/signup menggunakan akun Facebook.
- Memilih produk/theme yang ingin anda beli (bisa berupa daftar, popup, atau radio button tergantung layout).
- Memasukkan **kode kupon** jika anda punya.
- Mencentang Anti SPAM jika diminta.

Setelah semua data benar, klik **Next** untuk lanjut ke tahap pembayaran.

## 3. Memilih Metode Pembayaran

Umumnya tersedia beberapa metode pembayaran:

- **PayPal**
  - Setelah klik Next, anda akan diarahkan ke situs PayPal.
  - Login ke akun PayPal, lalu lakukan pembayaran sesuai instruksi.
  - Jika pembayaran berhasil, akun biasanya akan aktif otomatis dan anda dapat mendownload theme dari member area:  
    https://member.kentooz.com/member
  - Jika akun tidak aktif otomatis, silakan kontak support untuk verifikasi.

- **Offline Payment (Transfer Bank)**
  - Anda akan diarahkan ke halaman instruksi pembayaran offline.
  - Anda juga menerima email **Pending Invoice** dari Kentooz (cek juga folder SPAM jika tidak masuk inbox).

Setelah transfer:
- Lakukan **konfirmasi pembayaran** sesuai petunjuk di email/invoice (biasanya via email support atau form konfirmasi).

## 5. Aktivasi dan Download Produk

Setelah pembayaran terkonfirmasi:

1. Tim akan mengaktifkan akun dan langganan anda (proses manual setelah membaca email konfirmasi).
2. Setelah aktif, anda bisa masuk ke member area:  
   https://member.kentooz.com/member
3. Di halaman member, anda bisa:
   - Melihat daftar produk yang dibeli.
   - Mendownload file theme dan plugin yang menyertai.

Jika setelah beberapa waktu akun belum aktif:
- Cek ulang email (termasuk SPAM) untuk informasi lanjutan.
- [Hubungi support Idtheme/Kentooz](https://www.idtheme.com/kontak-kami/) dan sertakan bukti pembayaran.
