# Kebijakan Dukungan Idtheme

Dokumen ini menjelaskan cakupan dukungan yang diberikan Idtheme untuk produk theme dan plugin yang dijual.

## Siapa yang Berhak Mendapat Dukungan

- Semua pembeli resmi yang membeli langsung dari Idtheme / Kentooz:
  - Baik lisensi Developer maupun Personal.
- Jika anda membeli produk dari pemegang lisensi Developer:
  - Mintalah bantuan terlebih dahulu ke pemegang lisensi tersebut.
  - Jika diperlukan, pemegang lisensi Developer akan menghubungi Idtheme untuk bantuan tambahan.
- Jika anda membeli dari pihak ketiga dengan lisensi tidak resmi:
  - Anda **tidak berhak** mendapatkan dukungan maupun manfaat lainnya.

Untuk permintaan bantuan via email atau WhatsApp:
- Idtheme dapat meminta anda:
  - Mengirim email menggunakan **email pembelian** pada Kentooz.
  - Mengirim WhatsApp menggunakan **nomor yang tertera di akun member** anda.

## Cakupan Layanan Dukungan

Idtheme hanya memberikan dukungan untuk **produk resmi** yang dijual di idtheme.com.

Layanan dukungan mencakup:

- Bantuan instalasi theme/plugin.
- Bantuan konfigurasi dan penggunaan dasar produk.
- Bantuan jika terjadi fatal error terkait theme/plugin Idtheme (dengan catatan anda menggunakan versi terbaru theme/plugin dan WordPress).

Jika anda memerlukan bantuan untuk mengatur atau mengonfigurasi theme:

- Disarankan membaca dokumentasi theme terlebih dahulu.
- Banyak pertanyaan umum sudah terjawab di dokumentasi.
- Jika belum terjawab, anda dapat:
  - Mengirim tiket melalui helpdesk.
  - Mengirim email ke alamat support yang disediakan.

## Perbaikan Bug

Jika ditemukan bug pada theme atau plugin:

- Tim Idtheme akan berusaha memperbaikinya secepat mungkin setelah melakukan pengecekan.
- Dalam beberapa kasus:
  - Anda akan diberikan solusi sementara (patch/manual fix) sebelum update resmi dirilis.
  - Jika anda kesulitan mengikuti panduan perbaikan, Idtheme mungkin meminta akses ke situs anda untuk memeriksa dan memperbaiki bug tersebut secara langsung.

## Hal yang Tidak Dicakup Dukungan

Beberapa hal berikut umumnya **tidak** dicakup oleh dukungan standar:

- Bugs atau konflik yang berasal dari plugin pihak ketiga:
  - Idtheme dapat meminta anda menonaktifkan plugin pihak ketiga ketika troubleshooting.
- Dukungan WordPress umum (di luar produk Idtheme), misalnya:
  - Cara instal WordPress di hosting tertentu.
  - Pengaturan server nginx, optimasi server, dsb.
  - Untuk hal ini, rujuk ke dokumentasi WordPress.org atau penyedia hosting.
- Kustomisasi kode berat:
  - Membuat fitur baru kompleks.
  - Menulis fungsi custom besar di luar ruang lingkup theme.
- Idtheme biasanya hanya membantu kustomisasi ringan yang masih terkait fitur theme.

Jika anda membutuhkan kustomisasi lanjutan:
- Disarankan mencari freelancer, misalnya di:
  - projects.co.id
  - freelancer.co.id
  - Forum PHP atau komunitas developer lainnya.

## Informasi Umum Mengenai Dukungan

- Dukungan dijawab ketika tim online.
- Jadwal:
  - Senin–Minggu tim online, namun:
  - Sabtu dan Minggu biasanya respon lebih lambat (slow response).
- Tersedia grup Facebook untuk diskusi/dukungan komunitas, linknya bisa dilihat di member area.
