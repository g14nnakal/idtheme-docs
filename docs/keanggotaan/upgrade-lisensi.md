# Upgrade Lisensi Theme

Jika anda sebelumnya membeli theme dengan lisensi lebih rendah (misalnya Personal) dan ingin meng-upgrade ke lisensi lebih tinggi (misalnya Developer atau domain lebih banyak), anda bisa melakukannya langsung dari member area Kentooz.

## 1. Cek Apakah Theme Mendukung Upgrade Lisensi

Tidak semua theme mendukung upgrade lisensi.  
Beberapa theme hanya menyediakan satu jenis lisensi, sedangkan yang lain memiliki opsi upgrade ke:
- Lisensi Developer
- Lisensi multi-domain (misalnya 5 domain, 200 domain, dll)

Untuk mengecek:

1. Login ke akun Kentooz anda.
2. Buka halaman **Active Subscriptions / Langganan Aktif**.
3. Jika theme yang anda miliki mendukung upgrade, akan muncul tombol **Upgrade** pada subscription tersebut.

Contoh tampilan tombol upgrade bisa berbeda untuk setiap periode, tetapi biasanya berada di sebelah informasi langganan/theme yang aktif. Berikut contoh gambar nya:

![Contoh Tombol Upgrade Lisensi](/keanggotaan/upgrade-license/upgrade-button-idtheme.jpg)

## 2. Memilih Jenis Upgrade

Setelah klik tombol **Upgrade**:

1. Akan muncul popup pilihan tipe upgrade.
2. Pilih jenis upgrade yang diinginkan, misalnya:
   - Upgrade ke 5 domain.
   - Upgrade ke 200 domain.
   - Upgrade ke lisensi Developer.
3. Pilihan yang muncul tergantung pada theme dan paket yang tersedia.

## 3. Menyelesaikan Proses Upgrade

Setelah memilih tipe upgrade:

1. Klik **Upgrade Subscription / Upgrade Berlangganan**.
2. Anda akan diarahkan ke metode pembayaran yang sama seperti saat pembelian awal (misalnya PayPal atau transfer bank).
3. Lanjutkan proses pembayaran sampai selesai.

Setelah pembayaran terkonfirmasi:

- Subscription anda akan di-upgrade ke lisensi baru.
- Harga upgrade biasanya adalah selisih dari lisensi lama ke lisensi baru (detail mengikuti sistem Kentooz).

## 4. Perubahan License Key

Catatan penting:

- Setelah upgrade lisensi, **license key lama akan otomatis tidak berlaku**.
- Sistem akan menghasilkan **license key baru** sesuai lisensi yang baru.
- Anda perlu:
  - Mengupdate license key di website yang menggunakan theme tersebut.
  - Menghapus atau mengganti license key lama dengan yang baru.

Jika anda ingin **membeli license key baru** tetapi tetap mempertahankan license key lama (misalnya untuk domain terpisah):
- Jangan menggunakan fitur upgrade.
- Lakukan pembelian baru untuk license tambahan.
