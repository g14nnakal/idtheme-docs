# Instalasi dan Pengaturan Majalahpro

## Video Tutorial

Sebelum anda melangkah install Majalahpro, sebaiknya lihat video di atas sampai selesai.

<YouTubeEmbed video-id="DRwF_0E5aDU" />

## Langkah Instalasi

1. Download terlebih dahulu theme Majalahpro dari member area.
2. Extract paket yang anda unduh.
3. Upload file `majalahpro.zip` melalui **Appearance -> Themes -> Add New -> Upload Theme**.
4. Aktifkan theme **Majalahpro**.
5. Instal rekomendasi dan required plugin yang diminta lalu aktifkan semuanya.

## Aktivasi Lisensi

1. Masuk ke **Plugins -> Majalahpro License**.
2. Masukkan **license key** yang anda dapatkan dari member area Kentooz:  
   https://member.kentooz.com/softsale/license
3. Simpan dan pastikan status lisensi aktif.

## Import Demo Data

1. Masuk ke **Appearance -> Import Demo Data**.
2. Klik tombol **Import Demo Data**.
3. Tunggu beberapa menit sampai proses selesai.
4. Setelah selesai, tampilan website akan mirip dengan demo resmi theme Majalahpro.
5. Lanjutkan dengan menyetel widget dan customizer.

## Pengaturan Majalahpro Core

Plugin **majalahpro-core** berisi pengaturan fitur utama theme.  
Masuk ke **Settings -> Majalahpro Core**. Contoh gambar pengaturan di Majalahpro core:

![Majalahpro Core Plugin Settings](/majalahpro/install-pengaturan/majalahpro-core-settings.jpg)

- **Tab Author Box**
  - Mengaktifkan/menonaktifkan author box.
  - Mengatur teks dan tampilan author box (warna, gaya).

- **Tab Related Posts**
  - Mengaktifkan/menonaktifkan related posts.
  - Mengatur jumlah posting yang tampil di related posts.
  - Terdapat hingga 3 jenis related posts yang dapat diatur (misalnya di bawah konten, di sidebar, dsb).

- **Tab Breadcrumbs**
  - Mengaktifkan breadcrumbs.
  - Mengatur teks label dan separator.

- **Tab Gallery**
  - Mengaktifkan gallery di post.
  - Mengatur tampilan gallery dan opsi lain yang terkait.

- **Tab Ads**
  - Mengatur kode iklan untuk semua posisi yang disediakan theme (header, sidebar, dalam konten, footer, dll).
  - Mengaktifkan script anti adblock jika diperlukan.

- **Tab Social**
  - Mengatur tombol social share.
  - Mengatur opengraph (jika anda belum menggunakan plugin SEO yang menangani OG).

- **Tab Ajax & Content**
  - Mengatur navigasi dengan **infinite scroll** atau menonaktifkannya.
  - Mengatur perilaku pemuatan konten via Ajax (misalnya ajax tab di homepage).

- **Tab Other**
  - Mengatur script di **head** dan **footer** (Google Analytics, Facebook Pixel, script lain).
  - Opsi optimasi seperti menonaktifkan script emoji, script version dan lain-lain.

## Pengaturan Style via Customizer

Masuk ke **Appearance -> Customize** untuk pengaturan tampilan. Contoh gambar pengaturan di Customizer:

![Majalahpro Customizer Settings](/majalahpro/install-pengaturan/majalahpro-customizer.jpg)

### Tab General

- Mengatur layout umum (boxed / fullwidth).
- Mengatur warna umum (background, primary color, link color).
- Mengatur gambar latar belakang website.
- Mengatur font:
  - Menggunakan Google Fonts.
  - Mengatur ukuran dan warna heading dan body text.

### Tab Header

- Mengatur icon dan logo.
- Mengatur warna latar header.
- Mengatur gambar latar header.
- Mengatur layout dan warna menu header.

### Tab Homepage

- Mengatur **ajax slider** pada homepage.
- Mengatur **ajax tab** (tab konten dinamis) pada homepage.

### Tab Blog

- Mengatur layout blog:
  - Sticky sidebar.
  - Navigasi situs.
  - Blog content.

### Tab Footer

- Mengatur warna latar footer.
- Mengatur tulisan copyright.
- Mengatur jumlah widget yang tampil di footer (misalnya 3 atau 4 kolom).

### Tab Menus

- Mengatur menu navigasi (lihat dokumentasi pengaturan menu).

### Tab Widgets

- Mengatur module dan sidebar yang tersedia di theme.

### Tab Additional CSS

- Menambahkan custom CSS jika anda membutuhkan kustomisasi lanjutan.

## Persyaratan Server

- Apache dengan PHP versi 7.2 ke atas.
- WordPress versi 5 ke atas (disarankan menggunakan versi terbaru).
- Curl Module dan OpenSSL aktif (wajib).

Karena faktor keamanan, sangat disarankan untuk menggunakan versi PHP yang lebih baru dari 7.2.
