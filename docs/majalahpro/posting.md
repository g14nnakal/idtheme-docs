# Cara Posting di Majalahpro

Majalahpro mendukung beberapa format post yang umum digunakan untuk blog/majalah online.

## Format Post
- Standard: posting biasa dengan featured image.
- Video: gunakan post format Video, isi sumber video via Oembed atau Iframe di Video Settings.
- Gallery: gunakan block Gallery Gutenberg atau insert gallery di Classic Editor.

Berikut contoh pengaturan post format:

![Post Format Settings](/general/post/post-format-video.png)

## Langkah Posting Standard
- Posts > Add New.
- Isi judul, konten, kategori, tag.
- Set featured image. [Tutorial featured image.](https://wordpress.com/support/featured-images/)
- Publish.

## Posting Video
- Ganti post format ke Video.
- Di Video Settings: pilih Oembed dan tempelkan URL YouTube/Dailymotion, atau gunakan Iframe. [Tutorial embed video.](https://codex.wordpress.org/Embeds)
- Set featured image. [Tutorial featured image.](https://wordpress.com/support/featured-images/)
- Publish.

Berikut contoh video settings:

![Video Settings](/general/post/video-settings.jpg)

## Posting Gallery
- Ganti post format ke Gallery.
- Tambahkan gambar via block Gallery atau insert gallery.
- Set featured image. [Tutorial featured image.](https://wordpress.com/support/featured-images/)
- Publish.

## Split Post
- Pisah artikel menjadi beberapa halaman dengan menyisipkan: `<!--nextpage-->` di Classic Editor atau bisa menggunakan `page break` di Gutenberg Editor. [Tutorial split post.](https://wordpress.com/support/wordpress-editor/blocks/page-break-block/)

## Tips Penulisan Konten di Majalahpro

- Gunakan kategori untuk mengelompokkan topik utama.
- Gunakan tag secukupnya (jangan berlebihan).
- Pastikan setiap posting memiliki featured image agar layout tema tampil maksimal.
