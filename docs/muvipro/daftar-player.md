# Daftar Player yang Umum Digunakan di Muvipro

Theme Muvipro tidak menyediakan file video sendiri, melainkan menampilkan player dari sumber eksternal (embed atau link). Berikut adalah contoh jenis player/sumber yang biasa digunakan pengguna:

- Embed dari layanan streaming pihak ketiga.
- File video di server pribadi atau CDN.
- Player HTML5 dengan link langsung ke file `.mp4` atau HLS.

> Selalu patuhi ketentuan hak cipta dan TOS dari layanan yang anda gunakan.

## Menggunakan Player di Muvipro

Pada meta box player di posting Movie/Episode:

- Masukkan embed code iframe, misalnya:

```html
<iframe src="https://contoh-streaming.com/embed/film-123" frameborder="0" allowfullscreen></iframe>
```

- Atau masukkan URL video jika theme menyediakan player internal.
