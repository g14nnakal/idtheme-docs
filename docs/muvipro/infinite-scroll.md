# Pengaturan Infinite Scroll Muvipro

Muvipro mendukung infinite scroll (load more otomatis) untuk halaman arsip menggunakan modul dari Jetpack atau integrasi bawaan theme.

## Catatan

- Untuk versi lama Muvipro (1.0.4 dan sebelum), infinite scroll harus menggunakan plugin jetpack, versi terbaru sudah tidak diperlukan lagi jetpack dan hanya menggunakan fitur bawaan theme.

## Mengaktifkan Infinite Scroll

1. Masuk **Customizer -> Movie -> Movie Layout**.
2. Atur **Blog Navigation Type** sesuai kebutuhan:
   - **Infinite Scroll:** Load more otomatis saat user mencapai bagian bawah halaman.
   - **Button Click:** Tombol “Load more posts” di bawah halaman.
   - **Pagination:** Navigasi halaman standar (1, 2, 3, dst).

## Tips Penggunaan Infinite Scroll
- Pastikan tema dan plugin Anda diperbarui untuk kompatibilitas terbaik.
- Uji performa:
  - Infinite scroll bisa membuat halaman terasa lebih “berat” jika terlalu banyak item dimuat.
  - Gunakan jumlah post per load yang masuk akal.
