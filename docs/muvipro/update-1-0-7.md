# Update Muvipro v1.0.7

Versi 1.0.7 Muvipro berisi penyempurnaan dari fitur yang telah ada dan mungkin penambahan opsi baru (lihat changelog resmi).

## Tambah Custom Page

Pada theme muvipro versi 1.0.7 terdapat tambahan custom page Order by date dan Order by modified, yaitu untuk menampilkan posting movie berdasarkan tanggal terbaru ataupun menampilkan posting movie berdasarkan modifikasi terbaru.

![Custom Page Muvipro v.1.0.7](/muvipro/v-1-0-7/custom-page.jpg)

## Widget

Merubah Pengaturan Widget dari Multiselect menjadi autocomplate dan menambah pengaturan orderby rand, date dan modified.

![Pengaturan Baru Widget Muvipro v.1.0.7](/muvipro/v-1-0-7/pengaturan-baru-widget-dan-seleksi-autocomplate.jpg)

Sebelumnya widget post, movie atau module menggunakan multi seleksi, dengan alasan performa karena jika sampai ribuan tag maka dashboard wordpress akan terasa berat, maka diubah menggunakan ajax autocomplate.

Dan terdapat pengaturan baru yaitu **Orderby Random, Date atau Modifikasi**. Pengaturan ini berfungsi untuk mengurutkan posting anda berdasarkan Tanggal Posting, Random atau berdasarkan tanggal modifikasi.

# Fitur Fokus Menu

![Fokus Menu Muvipro v.1.0.7](/muvipro/v-1-0-7/fokus-menu.jpg)

Silahkan anda lihat gambar diatas, terdapat menu dengan background hitam dan tulisan tebal, itu adalah fokus menu di theme muvipro. 

Untuk menambahkan nya baca langkah berikut:
- Masuk ke **Appearances -> Menus**.
- Pilih salah satu link yang ingin anda fokuskan.
- Masukkan kode **focus-menu** pada pilihan CSS Class.
- Setelah itu tinggal save saja.

## Fitur Lainnya di Idmuvi Core

Selain fitur diatas, terdapat juga penambahan fitur di plugin Idmuvi Core, yaitu:

- Remove Jquery Migrate.
- Remove WP Oembed.
- Remove WP Head Meta Tag.

## Rekomendasi Setelah Update

1. Backup situs sebelum update.
2. Update theme Muvipro ke v1.0.7.
3. Clear cache (plugin dan CDN).
4. Uji:
   - Halaman home.
   - Halaman single movie dan episode.
   - Fitur Ajax Search dan top navigation (jika digunakan).
