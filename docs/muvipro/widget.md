## Area Widget di Muvipro

Theme Muvipro biasanya menyediakan beberapa area widget, misalnya:

- **Blog Sidebar**: Sidebar yang muncul pada post type blog atau pada postingan blog.
- **Sidebar**: Adalah sidebar default yang muncul di semua halaman
- **Home module**: Adalah tempat widget yang akan muncul pada halaman home (index). Letaknya setelah menu.
- **Footer 1 – Footer 4**: Widget yang akan tampil pada footer di semua halaman. Footer widget akan muncul pada halaman widget jika anda mengatur jumlah widget yang tampil pada footer, misal anda setting 4 maka akan muncul Footer 1 – Footer 4.

Lihat contoh gambar dibawah:

![Area Widget Muvipro](/muvipro/widget/widget-area-muvipro.jpg)

Anda dapat melihat daftar area widget di:
**Appearance -> Widgets** (atau **Appearance -> Customize -> Widgets**).

## Menambahkan Widget

1. Masuk ke **Appearance -> Widgets**.
2. Pilih area widget di sisi kanan (Sidebar, Footer 1, Footer 2, dsb).
3. Dari daftar widget yang tersedia di sisi kiri:
   - Drag & drop widget ke area tujuan, atau
   - Klik widget, pilih area tujuan, lalu klik **Add Widget**.
4. Atur opsi widget (judul, jumlah item, kategori, dsb) lalu klik **Save**.

## Widget Khusus Muvipro (Termasuk Muvipro Core Plugin)

Biasanya theme Muvipro menyertakan widget khusus, berikut adalah widget yang tersedia pada theme ini:

- **Category Blog (Idmuvi)**. Menampilkan list category untuk blog post type (rekomendasi taruh di tempat widget blog sidebar).
- **Module Posts (Muvipro)**. Menampilkan grid list untuk movie dan TV Shows post type (rekomendasi taruh di tempat widget Home Module). Dan tidak support di tempat widget lainnya. Hanya support untuk Home Module.
- **Most View Movies (Idmuvi)**. Menampilkan list untuk movie dan TV Shows post type berdasarkan yang paling banyak dilihat (rekomendasi taruh di tempat widget Sidebar Atau Footer).
- **Movie Search (Idmuvi)**. Menampilkan advance search untuk movie dan TV Shows post type (rekomendasi taruh di tempat widget Sidebar).
- **Recent Blogs (Idmuvi)**. Menampilkan list untuk blog post type (rekomendasi taruh di tempat widget Blog Sidebar Atau Footer).
- **Recent Movies (Idmuvi)**. Menampilkan list untuk movie dan TV Shows post type (rekomendasi taruh di tempat widget Sidebar Atau Footer).
- **Search Blog (Idmuvi)**. Menampilkan form search untuk blog post type (rekomendasi taruh di tempat widget Blog Sidebar Atau Footer).

Silakan lihat nama widget yang berawalan **Muvipro** atau **Idmuvi** di daftar widget.

> [!NOTE]
> Untuk mengubah jumlah kolom Footer widget yang tampil, silahkan anda masuk ke **Customizer -> Footer -> Footer Widget** dan silahkan anda ubah jumlah kolom nya.

## Tips Penempatan Widget

- Gunakan **sidebar utama** untuk:
  - Pencarian (search).
  - Daftar film/episode terbaru atau terpopuler.
- Gunakan **footer widget** untuk:
  - Informasi singkat situs.
  - Menu link tambahan (FAQ, Kontak).
  - Social icon.
