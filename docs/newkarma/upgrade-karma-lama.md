# Cara Upgrade Karma Lama ke Newkarma Secara Gratis

Jika anda pernah membeli theme berita **Karma** (versi lama), anda bisa melakukan upgrade ke theme **Newkarma** dengan lisensi 1 domain secara gratis.

## Perbedaan Karma Lama dan Newkarma

- **Framework dan fitur berbeda**:
  - Newkarma menggunakan framework dan struktur yang lebih baru.
  - Fitur, layout, dan cara pengaturan juga berbeda.
- **Tidak bisa upgrade “langsung” tanpa penyesuaian**:
  - Jika anda menggunakan theme Karma lama, setelah ganti ke Newkarma anda perlu mengatur ulang tampilan dari awal (Customizer, widget, dsb).

## Langkah Umum Upgrade

1. **Pastikan anda pernah membeli theme Karma lama secara resmi.**
2. Baca dokumentasi kategori **Newkarma** untuk memahami:
   - Instalasi theme.
   - Pengaturan Newkarma Core.
   - Pengaturan Customizer.
3. Gunakan panduan upgrade lisensi Kentooz/Idtheme:
   - Ikuti prosedur upgrade lisensi resmi:  
     https://www.idtheme.com/docs/cara-upgrade-lisensi-untuk-theme-kentooz-atau-idtheme/

Setelah proses upgrade lisensi selesai, anda akan mendapatkan akses ke theme Newkarma.

## Konfirmasi ke Developer

Setelah melakukan upgrade:

1. Lakukan **konfirmasi** ke tim Idtheme/Kentooz:
   - Gunakan halaman kontak resmi:  
     https://www.idtheme.com/kontak-kami/
   - Sertakan:
     - Data pembelian Karma lama.
     - Email akun member area.
     - Informasi domain yang akan menggunakan Newkarma.
2. Tim akan memverifikasi dan memastikan lisensi Newkarma aktif sesuai ketentuan.

## Catatan tentang Halaman Depan (Front Page)

Ada perbedaan penting antara Karma lama dan Newkarma:

- **Karma lama**:
  - Menggunakan **static front page** (Front Page) sebagai halaman depan.
- **Newkarma**:
  - Menggunakan **latest posts** (posting terbaru) sebagai halaman depan.

Jika setelah upgrade tampilan tidak sesuai, cek pengaturan:

1. Masuk ke **Settings → Reading**.
2. Pada **Your homepage displays**:
   - Pilih **Your latest posts** untuk mengikuti standar Newkarma.
3. Simpan perubahan.

Karena itu, disarankan untuk segera melakukan upgrade jika anda masih menggunakan salah satu dari theme lama tersebut.

## Ringkasan

- Upgrade dari Karma lama ke Newkarma **gratis** untuk 1 domain.
- Newkarma adalah theme baru dengan struktur dan fitur berbeda, sehingga perlu pengaturan ulang.
- Pastikan mengikuti:
  - Panduan instalasi & pengaturan Newkarma.
  - Panduan upgrade lisensi resmi.
  - Pengaturan Reading (latest posts) setelah beralih ke Newkarma.

Jika ada kendala saat proses upgrade atau aktivasi lisensi, silakan langsung menghubungi support Idtheme/Kentooz melalui halaman kontak resmi.
