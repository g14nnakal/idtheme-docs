# Instalasi dan Import Demo Theme Salespro

Theme **Salespro** dirancang untuk landing page dan penjualan produk dengan dukungan Elementor.

## Video Tutorial

Pada dokumentasi asli tersedia video panduan instalasi.  
Sebaiknya anda menontonnya terlebih dahulu.

<YouTubeEmbed video-id="MQOQtB_5nmY" />

## Langkah Instalasi
- Download file theme dari member area.
- Extract package yang sudah anda unduh, lalu anda upload salespro.zip melalui **Appearance > Themes > Upload Theme**.
- Activate theme **Salespro**.
- Instal dan aktifkan plugin **required** dan **recommended** (misalnya Elementor, plugin kontak, dsb).

## Pengaturan Jetpack (Jika Digunakan)

Beberapa fitur Salespro dapat memanfaatkan modul Jetpack, misalnya:

- **Contact Form**
- **Extra Sidebar Widgets**
- **Sharing**

Langkah:

1. Masuk ke menu **Jetpack** di dashboard.
2. Aktifkan modul yang diperlukan:
   - **Contact Form**
   - **Extra Sidebar Widgets**
   - **Sharing**

## Import Demo Data

Setelah theme dan plugin pendukung aktif:

1. Masuk ke **Appearance → Import Demo Data**.
2. Klik tombol **Import Demo Data**.
3. Tunggu beberapa menit hingga proses selesai.
4. Jika berhasil, tampilan website akan mirip dengan demo resmi Salespro.

Setelah import demo:

- Periksa halaman-halaman penting (Home, Landing Page, Blog).
- Atur ulang menu dan widget jika diperlukan.

## Penyesuaian Awal di Customizer

Sebagian besar pengaturan tampilan dapat diatur via:

- **Appearance → Customize**

Contoh pengaturan:

- Logo dan favicon.
- Warna utama dan tipografi.
- Pengaturan header/footer.
- Layout blog (jika digunakan blog).

## Persyaratan Server

- Apache dengan PHP **7.2 ke atas**.
- WordPress versi **5 ke atas** (disarankan versi terbaru).

Jika saat instalasi terjadi blank screen atau error:

- Pastikan versi PHP dan WordPress sesuai rekomendasi.
- Cek juga batas upload dan memory limit di server.
