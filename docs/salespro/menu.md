# Pengaturan Menu di Salespro

Salespro menggunakan sistem menu bawaan WordPress, sehingga cara mengaturnya mirip dengan theme Idtheme lainnya.

## Membuat Menu Utama

1. Masuk ke **Appearance → Menus**.
2. Jika belum ada menu:
   - Klik **Create a new menu**.
   - Beri nama menu, misalnya *Main Menu* atau *Primary*.
   - Klik **Create Menu**.
3. Tambahkan item menu:
   - Pilih halaman (Pages), posting (Posts), Custom Links, atau kategori.
   - Centang item yang ingin dimasukkan.
   - Klik **Add to Menu**.
4. Susun urutan dengan drag & drop.
5. Untuk membuat submenu (dropdown):
   - Geser item sedikit ke kanan di bawah item parent.

## Mengatur Lokasi Menu

1. Pada halaman **Menus**, masuk ke tab **Manage Locations** (atau bagian **Menu Settings**).
2. Pilih menu yang akan digunakan di lokasi:
   - **Primary Menu**: menu utama di header.
3. Klik **Save Changes**.

## Tips Penggunaan Menu di Landing Page

Salespro fokus pada landing page dan penjualan. Beberapa tips:

- Gunakan menu yang sederhana:
  - Home
  - Fitur
  - Testimoni
  - Harga
  - Kontak
- Jika menggunakan **one-page layout**:
  - Anda bisa membuat link menu yang mengarah ke **anchor ID** di halaman (misalnya `#features`, `#pricing`).
  - Gunakan **Custom Links** di menu:
    - URL: `#features`
    - Link Text: `Fitur`

Pastikan anchor ID di halaman sesuai dengan URL yang anda pakai pada menu.
