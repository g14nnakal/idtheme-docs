# Pengaturan Tempat Iklan / Banner Terbaru di Superfast 1.0.8

Mulai versi **1.0.8**, Superfast menambahkan fitur **Banner Between Posts** untuk menampilkan iklan di antara daftar artikel pada halaman indeks dan arsip.

## Banner Between Posts di Halaman Indeks/Arsip

1. Masuk ke **Settings → Idblog Core → Ads**.
2. Cari pengaturan **Banner Between Posts**.
3. Masukkan kode iklan anda (misalnya script AdSense atau banner HTML biasa).
4. Atur posisi iklan, misalnya:
   - Setelah post pertama.
   - Setelah post kedua.
   - Setelah post ketiga.
   - Setelah post keempat.
5. Simpan pengaturan.

Setelah disimpan, iklan akan muncul di antara daftar posting sesuai posisi yang anda pilih.

## Banner di Widget Recent Posts dan Most View Posts

Selain di loop utama, terdapat pengaturan banner di:

- Widget **Recent Posts (Idblog)**.
- Widget **Most View Posts (Idblog)**.

Langkah:

1. Masuk ke **Appearance → Widgets**.
2. Edit widget **Recent Posts (Idblog)** atau **Most View Posts (Idblog)**.
3. Di bagian paling bawah pengaturan widget, akan muncul opsi untuk banner.
4. Tempelkan kode iklan anda pada kolom yang tersedia.
5. Simpan widget.

Catatan:

- Untuk widget **Most View Posts (Idblog Core)** diperlukan plugin tambahan:
  - [WP PostViews](https://wordpress.org/plugins/wp-postviews/) atau [post views counter](https://wordpress.org/plugins/post-views-counter/).

## Versi Theme dan Plugin yang Didukung

Fitur banner terbaru ini hanya tersedia untuk:

- Theme Superfast minimal versi **1.0.8**.
- Plugin **Idblog Core** minimal versi **1.0.6**.

Pastikan anda sudah melakukan update theme dan plugin sebelum mencoba fitur ini.
