# Cara Mengatur Menu di Superfast

Pengaturan menu di Superfast mengikuti standar WordPress, sehingga cukup mudah dilakukan.

## Membuat Menu Baru

1. Masuk ke **Appearance → Menus**.
2. Jika belum ada menu:
   - Isi nama menu, misalnya `Main Menu`.
   - Klik **Create Menu**.
3. Di bagian **Add menu items** pilih:
   - **Pages**: halaman statis seperti Home, Contact, dsb.
   - **Posts**: posting tertentu (jarang dipakai sebagai menu utama).
   - **Custom Links**: untuk link eksternal atau anchor khusus.
   - **Categories**: kategori berita/artikel.
4. Centang item yang diinginkan, lalu klik **Add to Menu**.
5. Susun urutan menu dengan drag & drop.

## Mengatur Dropdown Menu

Untuk membuat menu dropdown:

1. Seret item menu sedikit ke kanan di bawah menu induknya.
2. Item tersebut akan menjadi submenu dari item di atasnya.
3. Ulangi untuk submenu lain sesuai kebutuhan.

Struktur contoh:

- Berita
  - Nasional
  - Internasional
  - Olahraga

## Menentukan Lokasi Menu

Theme Superfast biasanya menyediakan beberapa lokasi menu:

- **Primary** (menu utama di header).
- **Secondary** (jika diaktifkan, khusus top bar).

Atur di **Appearance > Menus > Manage Locations**, pilih menu untuk tiap lokasi lalu Save Changes.

## Mengatur Menu di Customizer

Anda juga dapat mengatur menu melalui:

- **Appearance → Customize → Menus**.

Keuntungannya:

- Dapat melihat preview secara real-time.
- Berguna untuk menyesuaikan warna header dan posisi menu bersamaan.

## Tips Struktur Menu di Superfast
- Solusi menambahkan icon pada menu:
[Tambahkan Icon Pada Menu](/general/icon-menu-theme-idtheme.md)
- Gunakan menu yang ringkas, tidak terlalu banyak level.
- Tempatkan kategori utama di level pertama.
- Subkategori di level kedua.
- Hindari membuat struktur yang membingungkan pengunjung.

Setelah selesai menyimpan, refresh halaman depan dan pastikan menu tampil sesuai keinginan.
