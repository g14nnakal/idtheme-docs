# Pengaturan Top Navigation di Theme Superfast

Superfast menyediakan area **Top Navigation** (top bar) untuk menampilkan menu tambahan di bagian atas situs, misalnya link ke halaman penting atau social link.

## Mengaktifkan Top Navigation

1. Masuk ke **Appearance → Menus**.
2. Buat menu baru atau gunakan menu yang sudah ada.
3. Tambahkan item-menu yang diinginkan (halaman, custom link, dsb).
4. Atur di **Appearance > Menus > Manage Locations**, pilih **Secondary** lalu Save Changes.
5. Klik **Save Menu**.

Setelah disimpan, menu akan tampil di bar bagian atas.

## Customize Top Navigation

### Pengaturan Baru Di Customizer untuk Top Navigation:

- Masuk ke **Appearance -> Customize -> Header -> Social & Top Navigation**.
- Atur top navigasi sesuai kebutuhan. Contoh screenshoot:

![Pengaturan Top Navigation Superfast](/superfast/top-navigation/top-navigation-superfast.jpg)

### Pengaturan Style Top Navigation:
- Masuk ke **Appearance -> Customize -> Header -> Header Color**.
- Atur warna background dan teks top navigation sesuai kebutuhan. Contoh screenshoot:

![Pengaturan Style Top Navigation Superfast](/superfast/top-navigation/top-navigation-style-superfast.jpg)

Sesuaikan dengan desain website anda agar tidak mengganggu fokus konten utama.

## Konten yang Cocok untuk Top Navigation

Contoh penggunaan:

- Link ke halaman **Tentang**, **Kontak**, atau **Kebijakan Privasi**.
- Link ke halaman **Login/Daftar**.
- Link ke social media (bisa melalui icon di header jika theme menyediakannya).

Hindari memasukkan terlalu banyak menu di top bar agar tampilan tetap bersih.
