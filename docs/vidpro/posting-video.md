# Cara Posting Video di Theme Vidpro

Vidpro berfokus pada konten video. Berikut langkah umum membuat posting video.

## Manual Posting Video

1. Masuk ke **Posts → Add New**.
2. Isi:
   - Judul Post.
   - Deskripsi/konten.
   - Kategori dan tag.
   - **Post Format: Video** (jika theme mendukung).
3. Cari metabox **Video Settings** (biasanya di bawah editor):
   - Terdiri dari 3 tab:
     - **Video Settings**
     - **Iframe/Multi Server**
     - **Download**
4. Di tab **Video Settings**, terdapat youtube ID:
   - Masukkan Id youtube nya saja
   - Maka akan otomatis melakukan embed.
   - Isi juga duration nya.
5. Jika menggunakan **Iframe/Multi Server**:
   - Masukkan kode `<iframe>` yang disediakan oleh platform video.
6. Pada Tab **Download**:
   - Anda dapat memasukkan link download pada postingan.
6. Pilih **Featured Image** untuk thumbnail.
   - [Tutorial featured image.](https://wordpress.com/support/featured-images/)
7. Klik **Publish**.
