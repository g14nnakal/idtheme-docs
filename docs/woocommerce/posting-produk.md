## 1. Tambah Produk Baru
1. Masuk ke **Products → Add New**.
2. Isi **Product name** dan deskripsi utama.
3. Pilih kategori produk dan tambahkan tags bila perlu.

## 2. Pengaturan Data Produk
Di meta box **Product data** pilih tipe:
- Simple product: produk tunggal tanpa variasi.
- Variable product: produk dengan variasi (warna/ukuran).
- Grouped product: kumpulan beberapa produk sederhana.
- External/Affiliate product: produk dijual di situs lain (link out).

### Harga dan Inventory
- Regular price dan Sale price (opsional, bisa dijadwalkan).
- SKU (kode unik), Manage stock, Quantity, dan status stok.

### Shipping
- Weight (berat) dan Dimensions (dimensi) untuk perhitungan ongkir.
- Shipping class jika menggunakan kebijakan ongkir berbeda.

### Linked Products
- Upsells dan Cross-sells untuk meningkatkan penjualan.

### Advanced
- Purchase note dan Menu order.

## 3. Variasi (untuk Variable Product)
1. Buka tab **Attributes**, tambah atribut (mis. Warna, Ukuran), centang “Used for variations”.
2. Buka tab **Variations**, buat variasi dari atribut yang ditambahkan.
3. Set harga, stok, dan gambar untuk masing-masing variasi.

## 4. Short Description dan Media
- Isi **Product short description** untuk ringkasan dekat tombol Add to cart.
- Atur **Product image** (gambar utama) dan **Product gallery** (gambar tambahan).

## 5. Publikasi
1. Periksa data dan pratinjau produk.
2. Klik **Publish**.
3. Verifikasi tampilan produk di halaman **Shop** dan detail produk.
