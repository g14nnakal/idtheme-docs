# Cara Mengganti Warna Kategori di Theme Idtheme

Saat ini untuk theme yang support hanya wpmedia, cara mengganti warna kategori di theme idtheme cukup mudah, silahkan anda masuk ke **Posts -> Categories**, Lihat gambar dibawah:

![Category Color Settings](/wpmedia/warna-kategori/wpmedia-categories-color-settings.jpg)

Nah setelah itu anda silahkan edit category atau add category baru disana ada settingan warna “Color category”, nah anda ubah saja warna nya disana, cek gambar dibawah:

![Category Color Picker](/wpmedia/warna-kategori/wpmedia-categories-color-options.jpg)

Selesai.
